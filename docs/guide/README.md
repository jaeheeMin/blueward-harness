# 하네스 작업 길잡이

팀원용 안내 페이지 "하네스 작업 길잡이" 의 원본이다. public-cloud 와
blueward-harness 를 처음 쓰는 팀원이 액티비티(하려는 일)별로 주의사항·할 일·
기능을 한눈에 보는 페이지다.

- 원본: [`harness-guide.html`](harness-guide.html)
- 게시 위치: claude.ai 아티팩트 <https://claude.ai/artifact/HD5TUKWCEbaAkYE9vSUkR8>
  - 비공개로 시작했다. 공유는 소유자가 페이지의 Share 메뉴로 한다.

## 다시 올리는 법

병합만으로 페이지가 바뀌지 않는다. 게시본은 따로 올려야 한다.

1. `harness-guide.html` 을 고쳐 PR 로 병합한다.
2. Claude Code 세션에서 Artifact 도구로 위 URL 을 `url` 로 지정해 publish 한다.
   지정하지 않으면 새 아티팩트가 생기니 반드시 지정한다.
3. 다른 세션에서 처음 올릴 때는 먼저 `action: read` 로 게시본을 읽어야 한다.

## 언제 고치나

- 스킬·규칙·훅·검사 워크플로 동작을 바꾸는 PR 에서 해당 탭을 같이 고친다.
- public-cloud 쪽 변경(위험 경로, 운영 파일, 승인자 등)은 그 저장소 세션에서
  이 파일이 보이지 않는다. 이 저장소에 "길잡이 갱신" 이슈를 남겨 챙긴다.
- 고칠 때 레일 아래 "harness 0.10.xx 기준" 표기를 현재 플러그인 버전에 맞춘다.

## 파일 형식

`<title>` 부터 시작하는 조각(fragment)이다. 아티팩트 호스트가 doctype,
charset, `[hidden]` 규칙을 덧붙인다. 로컬에서 볼 때는 UTF-8 로 서빙해야 한글이
깨지지 않는다.

## 지켜 온 디자인 결정

바꾸지 않는다.

- 왼쪽 전체 높이 탭 레일. 좁은 화면에서는 위 가로 탭이 된다.
- 탭은 "하려는 일" 단위다.
- 라이트/다크 토글은 레일 제목 아래에 둔다.
- 글꼴은 손글씨다(#529). 기본은 감자꽃(Gamja Flower)이고, 레일의 "글씨" 칸에서
  손글씨(개구 + 나눔펜 · 푸어 스토리 · 하이 멜로디)와 정돈된 글씨(고운돋움 · 스타일리시 ·
  선플라워)로 바꿀 수 있다(고른 값은 `hg-font` 로
  기억). 코드는 JetBrains Mono 다. 글꼴은 Google Fonts 만 쓸 수 있다(아티팩트 CSP).
- 색은 모눈 공책 바탕에 주황(강조) · 청록(됨) · 겨자(주의) · 다홍(멈춤)이다. 다크
  바탕은 따뜻한 먹색(`#1E1C1A` 계열)이다. 초록 · 파랑 위주로 돌아가지 않는다.
- 손글씨는 작아 보여서 본문 18px, 줄 간격 1.8 이다. 글 속 코드는 줄바꿈을 허용해
  좁은 화면에서 넘치지 않게 한다.
- 문체는 반말에 간결하게.
- 줄임말(SRS, PR, MCP 등)은 탭마다 처음 나올 때 괄호에 풀네임을 붙인다(#531). 예: SRS(Software Requirements Specification).
  번호 꼴(REQ-002)은 제목 괄호가 이미 있으면 덧붙이지 않는다.
- 각 패널 순서: 이럴 때/이렇게 말해 → 쉽게 말하면 → 흐름 도식 → 내가 할 일/
  만들어지는 것 → 주의 → 이전·다음.
- `.todo li`, `.made li` 는 grid/flex 로 바꾸지 않는다. 코드·굵은 글씨가 섞인
  줄이 글자 단위로 쪼개진 버그가 있었다.
