# #901 prs 스킬이 엔진 표를 그대로 보여 주게 함

- 2026-11-11, 판 0.10.264.
- 증상: 팀원 세션에서 `/harness:prs` 결과가 표 없이 글로만 보였다. 엔진(`checker.pr_queue --mine`)은 0.10.258 로 직접 돌려 보면 "내가 지금 할 수 있는 일"·"내 PR 과 그 줄기" 두 표를 정상으로 낸다.
- 원인(추정, 그 세션 화면은 못 봄): 엔진 출력은 Claude 만 보고 사용자는 Claude 가 다시 쓴 답을 본다. SKILL.md 3단계가 "두 표를 보여 주고 쉬운 말로 풀어 준다" 뿐이라 표를 빼고 풀이만 전할 수 있었다. 세션 시작 알림은 훅이 "고치지 말고 그대로 보여 줘라" 를 붙여 표로 잘 나온다.
- 수정: SKILL.md 3단계를 "엔진 표를 답 맨 앞에 고치지 말고 그대로 붙이고, 그 아래 짧은 설명(지금 병합할 것·고칠 것과 이유·기다리는 것)" 으로 바꿨다. `--all`·`--verbose`·`--team` 도 같은 방식. 길잡이 prs 탭에 같은 문장을 넣었다.
- 확인 남음: 병합·배포 뒤 다른 세션에서 `/harness:prs` 로 표가 그대로 나오는지 본다.
