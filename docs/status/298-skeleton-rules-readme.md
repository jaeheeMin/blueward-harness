# #298 skeleton rules README 에 사용 객체 규칙·교차 검사 스위치 안내 (2026-10-13)

#287(`md_table`)·#292(교차 검사 스위치)에서 미결로 남긴 skeleton `rules/README.md` 안내를 넣었다. 그때는 이 저장소 세션의 훅이 구판 플러그인(엔진)을 써서 `md_table` 을 몰라 그 파일 편집을 막았다 — 세션은 처음 열 때 받은 플러그인 판을 계속 쓰므로, 디스크에 새 판을 받아도 `/reload-plugins` 전에는 훅이 바뀌지 않는다.

넣은 것: (1) `spec.yaml` 의 `md_table` 이 `## 사용 객체` 표를 본다는 설명과 엔진 v0.10.59 이상(`stable`)을 받게 된 뒤에만 켤 수 있다는 배포 순서, (2) `cross-checks/switches.yaml` 의 `번호_짝`·`객체_겹침` 스위치 — 끄는 법, 꺼지면 코멘트에 남는 한 줄, 파일이 없으면 둘 다 켬, 잘못된 값은 검사 불능, 하위 폴더에 두는 이유(로더는 `rules/` 최상위 `*.yaml` 만 문서 규칙으로 읽음), 엔진 v0.10.62 이상. #292 기록(`292-spec-object-overlap.md`)의 미결은 이것으로 해소된다. Plugin version 0.10.63.
