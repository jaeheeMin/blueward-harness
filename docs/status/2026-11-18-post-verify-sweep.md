## 고친 것(`theme-post.css`, Post 만)
1. **세션 오른쪽 기술·기록 탭 위 큰 빈 칸**: app.css 의 `.mt-40`·`.mt-64` 가 `!important` 라 Post 의 `margin-top: 12px` 덮기가 안 먹었다(실측 40·64px). Post 쪽도 `!important`.
2. **기록 탭 제목 두 번**: 탭 제목 `이 세션에서 일어난 일`(.po-ih) 아래 안쪽 h2 가 같은 글을 한 번 더 → 안쪽 h2 숨김(산출물 탭의 같은 처리와 같다).
3. **처리 안내가 오류처럼 빨강**: 입력칸 아래 `이 작업에 전달했어.`, `단계를 건너뛰었어.`, 되돌림 안내 같은 `.light .note-accent` 가 Post 강조색 #C73E31 이었는데, 실패 색 #C2372C 와 거의 같다. 같은 칸에 거절 사유도 나오므로 초록도 아닌 본문 글자색(--lightink)으로.
4. **`/` 자동완성 이름이 글자 중간에서 끊김**: 설명이 긴 줄에서 이름 칸이 눌려 `/appro|vals`, `/at|c`. 이름 칸을 줄지 않게(최대 60%, 긴 파일 경로는 그 안에서 줄바꿈).
5. **390 에서 자동완성 목록이 190px**: 목록이 입력칸(assist-wrap) 너비에 갇혀 설명이 한두 글자씩 줄바꿈. 목록 기준을 입력 줄(.comp) 전체로.
6. **설정 · 계정 한도 켜기 확인의 `바꾸기` 가 꺼진 단추처럼 회색**: 모양 클래스 없는 `pill` 이라 브라우저 기본 회색 → Post 주 단추(빨강 채움).
7. **홈 승인할 PR 링크가 흐린 글자뿐**: 검토 요청(PR) 칸(세션이 없을 때 따로 선 승인 칸 포함)의 `a.lm` 이 GitHub 링크인데 눌리는 줄로 안 보임 → Post 의 다른 글자 링크(건너뛰기·되돌리기)처럼 밑줄.
8. **홈 새 소식이 좁은 칸 하나에 721px**: 아래 칸 격자(300px × 4)에서 새 소식이 한 칸에 8줄을 담아 옆 세 칸 아래가 통째로 비었다 → 그 아래 프로젝트 준비 칸처럼 한 줄 전체, 줄은 300px 단으로(1440 에서 301px, 390 은 한 단).

확인: 고친 뒤 Post 라이트·다크 × 1440·390 에서 같은 화면을 다시 찍어 봤다(기술 탭 첫 칸 탭 위에서 91px→63px, 기록 제목 하나, 안내 글자 rgb(36,48,74)/rgb(243,238,227), 자동완성 이름 한 줄·390 에서 입력 줄 너비, 새 소식 높이 301px, 링크 밑줄, 가로 넘침 0).

## 독립 리뷰(서브에이전트 sonnet, 읽기 전용) 반영
- Sauce 로 새는 규칙 없음(추가 줄 모두 `:root[data-theme="post"]`), `.comp` 위치 변경은 assist 가 든 두 곳(세션 이어서 요청·sayBox)만 영향, 새 작업 화면(inline 목록)·첨부 칩·홈 brief·팀 기록 찾기 칸은 무해.
- 고침: 세션이 하나도 없을 때 승인할 PR 칸은 `.po-prslot` 밖(`restSlot`)에 서서 밑줄이 안 걸렸다 → `.approvals a.lm` 도 같은 규칙.
- 기록만: `.light .note-accent` 를 성공·실패가 같이 써서 이제 둘 다 본문색이다(전에는 둘 다 빨강) — 실패만 눈에 띄게 하려면 JS 에서 클래스를 나눠야 해 공유 코드 몫. 세션 없을 때 `po-rest` 의 새 소식은 전처럼 한 단(전체 너비라 문제 없음). 점검 탭 첫 칸 간격은 gap 12 + margin 12(기존 files 규칙과 같은 방식).

## 고치지 않음·판정 대기
- **터미널 세션의 도구 단추가 이유 없이 흐림**: 기술 탭 도구 칸이 모두 꺼져 있고 이유(`canSend` 거절 이유)는 단추 title 에만 있다. 공유 `flow-ui.js toolsRow` 라 Sauce 도 같다(Sauce 는 `자세히` 안). 기술 정보 표에 `실행 방식 터미널 세션` 은 보인다.
- **PiP 실패가 화면에 안 보임**: 실패하면 단추 title 만 바뀐다(해요체 `열지 못했어요`). 빌드된 번들 `post/office/office-post.js` 안이라 여기서 고치지 않았다. 실제 Chrome 에서 열리는지는 확인 못 함.
- **같은 PR 카드가 대화와 검사 탭에 두 번**: 올림·승인 기다림 세션은 대화 판에도, 오른쪽 검사 탭에도 같은 PR 카드가 있다(#1025 배치). 의도인지 판정 필요.
- **기억 요약 안내가 누른 곳과 떨어짐**: 기억 탭 `요약해서 계속하기` 의 결과 문구는 입력칸 아래에 나온다(공유 `followNote`).
- **입력칸 아래 안내가 남음**: deliver 단추를 누른 뒤에도 앞의 `이 작업에 전달했어.` 가 남아 있다(새로 쓰면 지워짐, 공유).
- 프로젝트를 고른 채 다른 프로젝트 세션을 주소로 열면 머리 줄이 `projC ⌄ work/projM` 처럼 고른 프로젝트와 세션 폴더를 같이 보인다(#1070 설계 범위, 손대지 않음).
