# #763 산출물 화면(G-14·G-15)을 확정 시안과 맞추기 — G-15 부분

## 원인

산출물 화면(`/docs`)은 xlsx 를 고르면 파일 카드(이름·크기·열기)만 보였다. 시안 G-15 의 제목 "고객 양식으로 뽑았어", 원본 → 양식 줄, 양식 칸 수, 넓은 미리보기 표, 비어 있는 칸 안내, 내려받기가 없었다. 왼쪽 목록은 G-15 에는 없고 G-14 에만 있다. G-14 도 줄이 파일 이름 두 줄이었고(시안은 이름 · 판 · 확장자 한 줄) 제목 아래 간격(16px)·눈썹 줄 높이(21px)·종이 위 도구줄(`SRS.md · v0.1` · 칩 · 뽑기)이 달랐다.

## 고친 것

| 화면 | 바꾼 것 |
|---|---|
| G-15 (가장 최근 산출물이 고객 양식 xlsx 일 때) | 목록 없이 결과 화면. 눈썹 "산출물 · 고객 양식", 제목 "고객 양식으로 뽑았어", 부제 `<원본> v0.1 → 고객사 <양식> 양식(xlsx)`, 카드(XLSX · 이름 · 크기 · 방금 · 양식 칸 n개 모두 채움 / n개 중 m개 채움 · `폴더에서 보기` · `내려받기`), `미리보기 · <시트> 시트` 표(첫 줄은 머리), 노란 `비어 있는 칸 n개` 안내, "AI에게 말하기" 입력칸(보내면 그 세션에 빈 칸을 채워 다시 뽑아 달라고 말을 보낸다). 오른쪽 위 `문서 목록 보기` 로 G-14 로 나간다(시안에는 없지만 목록에 못 가게 되면 기능이 사라진다) |
| G-14 | 목록 줄 = 이름(진하게는 고른 줄만) · `v0.1 · xlsx` 한 줄 + 칩. 크기·세션은 줄 title. `SRS.md` 는 "요구사항정의서". 오른쪽 머리 = 이름 · `v0.1 · 안 올림` 칩 · 열기 · 폴더에서 보기 · `xlsx로 뽑기`. 종이 위 도구줄(파일명 · 판 · `아직 안 올림` · 세션 · `xlsx로 뽑기`). 소제목 14px, 표는 아래 줄만. 범례는 시안 문장(확인 못 함 칩이 있을 때만 그 뜻을 덧붙임) |
| 목록에서 양식 xlsx 를 고른 때 | 같은 결과 내용(카드·표·안내·입력칸)을 오른쪽에 보인다 |

## 데이터와 한계 (지어내지 않는 것)

- 양식 칸 수 = 시트마다 첫 줄을 칸 이름으로 보고, 아래 내용 있는 줄 x 칸 이름 수. 비어 있는 칸은 칸 이름으로 모아 안내에 쓴다(`L.formCells`). 미리보기가 잘렸거나(행·열 상한) 시트를 못 읽었거나 내용 줄이 없으면 세지 않고 "양식 칸 수 확인 못 함".
- 원본 문서는 양식 이름으로 짐작한다(Backlog → 요구사항정의서, 개발사양서 → 개발 Spec, CTS → CTS 작업본, Role → Role 작업본, 매뉴얼 → 사용자 매뉴얼 작업본). 모르는 양식이면 원본 없이 `고객사 <양식> 양식(xlsx) v0.1`. 판은 산출 파일 이름의 판(SRS 문서 머리의 `버전:` 에서 온 값)이다.
- 시안은 "양식 칸 12개 모두 채움" 과 "비어 있는 칸 1개" 가 함께 있다. 구현은 비어 있으면 "n개 중 m개 채움" 이라 쓴다.
- 시안 눈썹은 `미리보기`(붙임). 요청 문구의 "미리 보기" 가 아니라 시안을 따랐다.
- `내려받기` 는 새 서버 경로 `GET /api/sessions/:id/files/download?path=` (열기와 같은 허용 확장자·작업 폴더 안 파일만, 20MB 까지, `Content-Disposition: attachment`).
- 훅 세션(콘솔이 띄우지 않은 세션)은 말을 보낼 수 없어 입력칸이 꺼지고 이유가 아래에 나온다(시안은 항상 켜짐).
