# #655·#654 매뉴얼 캡처 첫 로드 다시 열기와 창 가려짐 안내

## 배경
public-cloud DEV-008(생산실적 모니터링) 매뉴얼 캡처(100 테넌트)에서 첫 실행은 화면마다 "30초 안에 찾을 이름이 하나도 그려지지 않았다" 로 검사 불능이었고 다시 돌리면 됐다(#655). 창이 가려졌을 때는 "브라우저 응답을 기다리다 시간이 지났다" 로만 나와 원인을 알 수 없었다(#654).

## 바꾼 것
- `checker/manual_capture.py` `capture`: 화면 그리기 대기가 시간 초과면 그 화면을 한 번만 다시 열어 기다린다. 또 안 되면 "한 번 다시 열어도 같았다 … --timeout 을 늘려 다시 돈다" 를 붙여 검사 불능.
- `window_hint`: 화면 캡처 중 CDP 오류(응답 시간 초과 등)가 나면 `document.visibilityState` 와 창 상태(`Browser.getWindowBounds`)를 다시 읽어, 가려짐·최소화면 그 사실을, 못 읽으면 가능성을 사유에 붙인다.
- `plugins/harness/skills/manual/SKILL.md` 종료코드 설명에 두 안내.
- plugin.json 0.10.175(main 0.10.172, 열린 PR #674 0.10.173, #676 0.10.174).

## 시험
- `uv run pytest checker/tests/test_manual_capture.py -q` 156 통과·1 건너뜀(새 시험 3개: 다시 열어 성공, 두 번 다 실패 안내, 가려진 창 원인 안내).
- 실제 테넌트로 첫 로드 지연·가려짐을 일부러 재현하지는 못했다(가짜 탭 시험만).
