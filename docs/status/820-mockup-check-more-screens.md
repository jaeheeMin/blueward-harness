# #820 시안 치수 검사에 G-07·08·11·14·16~19 상태 추가 (2026-11-09)

## 상태를 만들며 알게 된 것

- 콘솔이 띄운 세션은 시작 점검(최신 내용 받기·하네스 판)이 끝나야 오른쪽 '만든 산출물' 칸이 나온다. `harness:sync`·`harness:version` Skill 이벤트로 끝낸 것으로 만든다(G-13 은 시안이 점검 카드를 보이는 화면이라 그대로 둔다).
- 바뀐 파일·브랜치는 세션이 처음 읽을 때 정해진다. SRS 에 줄을 더하는 일은 세션을 띄우기 전에 한다(`_managed_srs(req=True)`).
- 산출물 화면에서 고른 문서는 가장 나중에 바뀐 파일이다(G-14 상태에서 SRS 를 나중에 씀).
- 홈 '승인 기다리는 PR' 칸은 내 승인을 기다리는 남의 PR 이 있어야 나온다.
- 확인 못 함 판정은 사유 앞부분에 '확인하지 못' 같은 낱말이 있어야 한다(`hooks_api.CANNOT_CHECK_WORDS`).
