# Cozy Office 서버가 만든 화면 글 해요체 (디오라마 7회차, 2026-11-19)

## 배경

6회차(`2026-11-19-cozy-office-copy.md`)가 콘솔 static 화면 문구를 해요체로 바꿨지만, 처방 경계(서버 글은 받은 그대로) 때문에
웹 콘솔 서버(`plugins/harness/console/*.py`)가 만들어 화면에 그대로 내는 글은 반말로 남았다. 승인 카드 큰 제목(`risk.py` 사유),
해요체 문장 뒤에 이어 붙는 서버 이유(`trouble.py` 저장소 주소 · `devready.py` · `gitstate.py`), `e.message` 로 나가는 `HttpError` 오류 글,
MCP 연결 상태 이름(`store.py`)이 한 화면에서 해요체와 섞여 보였다. 이번에 그 글을 해요체로 바꿨다. 규칙은 6회차 것 그대로
(`.claude/handoff/assets/cozy-copy-world/glossary.md`). 서버 글을 쉬운 말로 바꾼 앞 기록은 `826-server-plain-words.md`(합니다체 → 반말).

## 목록을 만든 방법

1. 파이썬 `ast` 로 콘솔 .py 28개의 한글 문자열 상수를 뽑았다(docstring 제외, f-string 조각 포함) — 1064개.
2. 문장 끝이 반말(~어 · ~아 · ~해 · ~야 · ~줘 · ~다 …)인 것을 걸렀다 — 710개.
3. 파일 · 함수마다 나가는 길을 확인해 화면에 안 나가는 것을 뺐다(아래 「바꾸지 않은 글」).
   나가는 길: `HttpError(…)` → 응답 `error` → static js 의 `e.message`, API 응답의 `reason` · `label` · `error` · `text`,
   세션 기록(`add_log` → 세션 화면 「이 세션에서 일어난 일」), 대화 메모(`add_chat(…, "note")`), 승인 요청 `riskNote`(카드 제목 · 「묻는 이유」).
4. 남은 것을 해요체로 바꾸는 후보를 규칙으로 만들고 한 줄씩 읽어 고쳤다(연결 어미 「못해 」 를 문장 끝으로 잘못 본 것 2곳 빼기,
   능력 부정 「바뀐 점을 못 보여 줘」 → 「보여 줄 수 없어요」, 변수 뒤 이다 「'{단계}' 이야」 → 「지금은 '{단계}' 단계예요」,
   「Host 야」 → 「Host 값이에요」). 바꿀 때는 그 상수의 줄 범위 안에서 따옴표 · 중괄호로 둘러싸인 글자만 바꿨다(주석 · 다른 상수를 건드리지 않게).
5. 서버 글을 글자로 비교 · 치환하는 곳을 찾았다(아래 「비교 글자」).

## 길잡이 · 화면 코드 · 시험

- 길잡이 `docs/guide/harness-guide.html`: MCP 상태 이름을 옮겨 적은 한 곳(「상태(연결하지 못했어요 · 로그인이 필요해요)만 보이고」). 길잡이 본문 말투(반말)는 그대로 — 화면 글을 인용한 곳만.
- `static/app.js`: 대화 메모 예시 주석 하나(「기억을 요약했어요 · …」). 화면 문구 · 비교 글자는 안 바꿨다(위 표대로 그대로 맞음).
- 시험: `test_web_console.py` 26곳, `test_web_console_ui.py` 33곳(가짜 서버 응답과 기대값을 같은 새 글로), `test_trouble_console.py` 4곳.
- `store.py` MCP 상태 「연결됨」 → 「연결됐어요」: 반말은 아니지만 같은 목록의 다른 이름이 모두 해요체 문장이 돼 「abap-adt — 연결하지 못했어요」 옆에 「연결됨」 만 남는 게 어긋나서 같이 맞췄다(시험 기대값 함께).

## 남은 것

- `open.py`(터미널 · 바로가기 메시지 상자) 글은 반말 그대로다. 바로가기가 실패하면 Windows 메시지 상자에 이 출력이 그대로 실리고, `open.py` 성공 줄 끝에 해요체 바로가기 결과가 붙는다. 터미널 글은 Claude 가 읽는 출력이라 이번 경계 밖 — 맞출지는 사용자가 정한다.
- 판 올리기 · 새 소식은 안 했다(배포 파일 — 로컬 main 합류 때).
