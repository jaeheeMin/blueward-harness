# #348 Spec 화면 캡처 그림 넣기 (2026-10-19)

## 문제

개발사양서 화면 시트의 화면 그림(#335 C2)은 셀·병합으로 그린 목업뿐이라 실제 앱 화면 캡처를 못 넣는다. 사람이 엑셀에서 손으로 붙이면 산출물이 Spec 과 어긋나고 어느 판의 캡처인지 알 수 없다.

## 바뀐 것

- 지도: 시트 `화면:` 항목에 선택 키 `캡처: {영역, 설명}`(`checker/screen_draw.py` `_ITEM_KEYS`·`map_problems`). `영역` 생략 시 그 화면의 `영역`, `설명` 필수. 겹침 검사: 칸·표·서술·유지, 다른 화면의 모든 범위, 같은 화면의 설명↔그림 영역. 같은 화면의 그림 `영역` ↔ 캡처 `영역` 은 지도 오류가 아니다(둘 중 하나만 쓰면 되므로) — 한 작업본이 둘 다 쓰면 산출이 멈춘다.
- Spec 절 `#### <화면> 캡처`: 그림 한 줄 `![글](경로.png)` 정확히 하나 + `| 번호 | 설명 |` 표(1부터 연속). `screen_draw.capture_offenders` 가 `spec_offenders` 를 통해 저장 훅·PR(`form_columns`)에서 "양식 밖" 으로 거절한다. 지도에 `캡처` 가 없는 화면의 `캡처` 절도 양식 밖.
- 산출(`checker/screen_capture.py` 새 모듈, `export.build_form`): 검사 → 설명 칸 쓰기 → 맨 끝 zip 조립에서 drawing·media·rels·Content_Types·시트 `<drawing>` 을 붙인다. 남은 견본 검사는 템플릿 raw 를 보므로 새 그림을 견본으로 오인하지 않는다(설명 칸은 `ed.written` 이라 제외).
- 테스트 `checker/tests/test_screen_capture.py`.
- 문서: spec `SKILL.md`, `form-map.md` "화면 캡처", `checker/README.md`, 길잡이 Spec·산출 탭. Plugin version 0.10.86 → 0.10.87.

## 설계 결정

- **그림 경로는 저장소 루트 기준.** Spec 파일 위치와 무관하게 산출(`--root`)이 같은 경로를 읽는다. URL·절대 경로·`..`·역슬래시는 양식 밖. 권장 위치 `docs/spec/img/`.
- **판 번호.** 그림 파일 이름의 `_v<숫자.숫자>`(대소문자 무관, 여럿이면 마지막) 와 산출 파일 이름의 같은 패턴을 문자열로 비교한다. 어느 쪽이든 판을 못 찾으면 검사 불능이라 멈춘다(통과 아님).
- **크기.** 영역을 열 너비(`<cols>`, 숨긴 열 0, 기본 너비)·행 높이(`ht`, 숨긴 행 0, `defaultRowHeight`)로 EMU 로 환산하고 PNG 헤더의 픽셀을 96dpi(9525 EMU)로 본다. 비율을 지켜 줄이되 늘리지 않고(scale ≤ 1), 영역 왼쪽 위에 `oneCellAnchor` 로 붙인다. `MIN_SCALE = 0.5` 미만이면 멈춘다(정확히 50% 는 통과). 사유에 비율·영역·대안을 적는다.
- **이미 drawing 이 있는 시트는 거절.** 기존 drawing 에 앵커를 덧붙이면 id·rels 충돌 처리가 필요하다. 이번엔 "그림이 있는 시트" 로 멈추고 빈 양식(그림 지운 템플릿)을 쓰게 한다. 현재 개발사양서 템플릿은 `그림_지우기: true` 라 해당 없음.
- **설명 칸.** 범위 첫 열에 한 행씩 `① 설명`(21부터 `(21)`). 행 부족·견본 값 잔존(비우기 대상이 아닐 때)·병합의 왼쪽 위가 아닌 칸은 멈춘다. 설명 안 `<br>` 는 줄바꿈.
- 지도에 `캡처` 가 있는데 Spec 에 절이 없으면 `그림` 과 같게 거부하지 않고 경고. 캡처를 쓴 화면은 "그림 절이 없다" 경고를 내지 않는다.
- Pillow 의존성을 더하지 않았다(PNG 크기는 IHDR 만 읽음). 테스트에서 openpyxl 로 이미지 수를 확인하는 것은 Pillow 가 있을 때만(`importorskip`).

## 확인한 것

- 합성 템플릿 테스트와, 실제 개발사양서 템플릿·지도 사본(public-cloud, `견본_검사: true`)에 `캡처` 를 더해 산출해 보았다 — 문제 없이 산출, openpyxl 이 시트에서 그림 2개를 읽음, 설명 칸 확인, `<drawing r:id>` 는 `pageSetup` 뒤.

## 확인하지 못한 것

- **엑셀에서 복구 창 없이 열리는지** — 사람이 한 번 열어 확인해야 한다(drawing XML 은 oneCellAnchor + pic 의 최소 형태, 엑셀 실물 미확인).
- 크기 어림값(열 너비 7px/문자)이 실제 글꼴(맑은 고딕 등)에서 얼마나 어긋나는지 — 영역을 약간 넘거나 모자랄 수 있다.
- 자동 캡처(앱을 띄워 화면을 찍는 시험)는 이번 범위가 아니다.
- public-cloud 개발사양서 지도에 `캡처:` 를 넣는 일(영역·설명 범위 후보는 PR 설명 참고)과 빈 양식의 설명 칸 비우기는 그쪽 저장소 작업이다.
