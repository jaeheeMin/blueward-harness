- `static/post-logic.js`: `stateOf(s, L, openIds)` — openIds 를 받거나, 화면이 `useOpenIds(fn)` 로 한 번 알려 준 것을 쓴다. 목록 걸러보기 묶음 이름 「내 차례」 → 「할 일」(내 차례 + 막힘 + 확인 못 함, 세션 수). 홈·띠·알림의 「내 차례 N건」과 이름이 겹치지 않는다.
- `static/flow-ui.js`: `create` 에서 `BHPostLogic.useOpenIds(openIds)` — app.js·post-home.js 호출부를 고치지 않고 모든 stateOf(목록·아바타·장면·홈 표)가 같은 기준을 쓴다. 문서 목록 읽기를 `sessionDocs` 하나로 모아 409(작업 폴더 없음)는 `gone` 으로 따로 세고 세션 id·폴더별 5분 동안 다시 묻지 않는다. 산출물 탭·홈 최근 산출물에 「N개 세션은 작업 폴더가 없어져서(지운 폴더 등) 문서를 읽지 못했어. 그 세션의 문서는 목록에 없어.」(읽기 실패·git 못 읽음 문구와 섞지 않음). 모든 세션이 실패·폴더 없음이면 「확인 못 함」.
