# #610 웹 콘솔 질문 마감이 늦어지는 문제

## 증상

`test_question_times_out_after_300_seconds_with_injected_clock` 이 windows 러너에서만 가끔 실패했다(#602·#604 검사).
질문 훅 응답이 오지 않아 시험 클라이언트가 30초 시간 초과로 끝났다. #597 에서 시험 대기만 5초 → 30초로 늘렸지만 원인이 아니었다.

## 원인

`console/hooks_api.py` 의 질문 훅이 요청을 화면에 등록(`store.add_request`)한 **뒤에** "300초 뒤 터미널로 넘김" 마감을 계산했다.
시험은 요청이 화면에 보이자마자 시계를 299초 앞당기는데, 느린 러너에서는 그 사이 서버가 아직 마감을 계산하기 전이라
마감이 앞당긴 시각 + 300초로 잡혔다. 실제 사용에서도 등록이 늦으면 그만큼 터미널로 넘어가는 시점이 밀린다.

## 고친 것

- 마감을 요청 등록 전에(질문이 도착한 시점 기준으로) 계산한다.
- 시험 `test_question_deadline_counts_from_arrival_not_from_registration`: 등록 중에 시계를 100초 흘려도 도착부터 301초에 넘어가는지 본다.
- 판은 같은 PR(#602)의 0.10.155 에 함께 담았다(판 번호 순서를 지키려고).
