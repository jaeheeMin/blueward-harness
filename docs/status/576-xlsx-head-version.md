# #576 xlsx 작업본 머리 버전으로 산출 파일명 버전 붙이기 (2026-11-01)

## 배경

양식에 버전 칸이 없는 xlsx 지도(사용자권한관리·CTS 관리대장)는 파일명이 고정이라, 한 번 main 에 병합된 뒤 두 번째 산출부터 덮어쓰기 방지로 거부됐다. 지도에 `자리: 버전: {메타: 버전}` 을 두어도 작업본(`## 양식 항목` 원본) 산출은 머리의 `버전: 0.1` 줄을 읽지 않아 "파일 이름에 들어갈 버전 값이 없다" 로 거부됐다(SRS 원본과 pptx 지도만 읽었다).

## 바꾼 것

- `checker/export.py`: `build_form` 의 xlsx 경로가 작업본 머리 메타(`_head_meta`, pptx 가 쓰던 것)를 `_file_name` 에 넘긴다. 작업본의 `버전` 이 `x.y`(앞 `v` 허용) 모양이 아니면 없는 것으로 보아 빈 버전 파일명을 거부한다. SRS 원본 경로와 `{칸|표}` 자리는 그대로다.
- `plugins/harness/skills/spec/form-map.md`: `산출.자리` 의 `{메타}` 설명.
- 시험: `checker/tests/test_export.py` 에 머리 버전으로 `_v0.1` 산출, `v` 뗌, 줄 없음·빈 값·글자·`1`·`0.1.2` 거부, 표 버전 자리 회귀. `checker/tests/test_form_columns.py` 에 Spec 머리 `버전:` 줄이 양식 밖 검사에 안 걸리는 경우. Plugin version 0.10.146.

## 확인한 것

- 작업본의 `form_columns`(저장 훅 포함)는 `## 양식 항목` 절만 읽는다. 머리의 `버전:` 줄은 걸리지 않아 허용 목록을 고치지 않았다.
- pptx 지도의 버전 형식은 이 이슈에서 건드리지 않았다(파일명 패턴 검사에만 맡긴다).
