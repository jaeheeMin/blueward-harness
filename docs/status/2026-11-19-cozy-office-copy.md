# Cozy Office 화면 문구 해요체 · 「내 차례」 이름 바꾸기 (디오라마 6회차, 2026-11-19)

## 배경

사용자 지시: 「화면 문구는 해요체, AI 슬롭 없이. 오늘 탭에서 말했지만 모든 탭에 적용.」 「내 차례」 는 누구 차례인지 헷갈린다.
2~5회차는 색·장면·사람 그림·요약 자리만 고쳐 한 화면에 해요체(알림 말풍선·장면 버튼·작은 창)와 반말이 섞여 있었다.
웹 콘솔은 #840/#928 에서 존댓말 → 반말로 바꾼 적이 있다(`docs/status/935-console-banmal-leftovers.md`). 이번에 해요체로 다시 바꿨다.
문구는 Sauce 와 같이 쓰는 문자열이 많아 Sauce 화면 글도 같이 바뀐다(순수 문구 변경 — 모양·동작은 안 건드림).

## 용어 — 「내 차례」 를 바꾼 말과 까닭

| 쓰는 자리 | 옛 말 | 새 말 | 까닭 |
|---|---|---|---|
| 한 세션의 상태(칩·상태 줄·눈썹·알림 제목·메모 머리·정리 줄) | 내 차례 · 네 차례 · 내 차례야 · 내 답이 필요해 | **답을 기다려요** | 주어가 세션이라 「누가 기다리는지」 가 분명하다. 장면 번들 `LABEL` 과 같은 말 |
| 답할 일 건수 묶음(띠 「N건」 · Sauce 홈 타일 · 알림 설정) | 내 차례 N건 · 내 차례가 오면 | **답을 기다리는 일** (N건 · 이 생기면) | 건수(요청·고칠 PR·올릴 차례)를 세는 이름 |
| 답을 기다려요 + 막혔어요 + 확인하지 못했어요 세션 묶음(세션 수) | 걸러보기 「할 일」 · 접힌 레일 「내가 할 일」 · 메모 이름 「내 차례 메모」 | **나를 찾는 사람** | 5회차가 덱 머리·장면 버튼에 붙인 이름과 같은 사람들·같은 수다. 기준이 같으면 이름도 같게(5회차 원칙) |
| 빈 덱 | 지금 네 답을 기다리는 일이 없어. | 지금은 나를 찾는 사람이 없어요. | 덱 = 나를 찾는 사람. 번들 작은 창 빈 글과 같은 말 |
| 차례 글이 없는 덱 카드 제목(Sauce·Post) | 내 차례야 | 확인할 일이 있어요 | 눈썹이 이미 「답을 기다려요」 라 같은 말이 겹쳐서 |
| 질문 카드 눈썹 | 네 차례 · N분째 | 답을 기다려요 · N분째 | |
| 프로젝트 준비 카드 눈썹 | 네 차례 | 먼저 할 일 | 세션 상태가 아니라 사용자가 먼저 할 일 |

관계: **나를 찾는 사람 = 답을 기다려요 + 막혔어요 + 확인하지 못했어요(사람 = 세션 수)**, **답을 기다리는 일 = 답을 기다려요 세션들이 가진 답할 일(건수)**.

상태 이름 일곱(한 곳 `post-logic.js LABEL` — 번들 `office-post.ts LABEL` 과 같다): 답을 기다려요 / 막혔어요 / 확인하지 못했어요 / 일하는 중이에요 / 승인을 기다려요 / 끝났어요 / 쉬는 중이에요.
- `post-home.js ST_TEXT`(칩만 쓰던 짧은 이름 「내 차례」·「끝남」 …)는 지우고 `PS.LABEL` 하나로 합쳤다. `post-pipeline.js LABEL` 도 같은 일곱 말(그 파일은 node 시험이 따로 읽어 상수를 따로 둔다).
- 덱 카드 종류(`kindLabel`)의 막힘·확인 못 함은 상태 이름(「막혔어요」·「확인하지 못했어요」), 질문·승인·계획·확인·고쳐야 함은 요청 종류 명사 그대로.
- 기호가 붙은 태그: 「✕ 막혔어요」 · 「? 확인하지 못했어요」(세션 카드·표·먼저 할 일 칸·PR 칸·팀 기록).
- 세션 목록 한 줄(`flow-logic.js phaseSide`): 「승인을 기다려요 · PR #n」 · 「끝났어요 · PR #n 합쳐짐」.
- 숫자 앞 묶음 이름(걸러보기 탭 「전체 · 나를 찾는 사람 · 일하는 중 · 끝남」, Sauce 세기 줄 「일하는 중 N · 답을 기다리는 일 N · ✕ 막힘 N …」, 단계 칸 값 「3 / 4 승인 기다림」 「· 막힘」)은 명사로 뒀다 — 세는 이름이지 상태 문장이 아니다.

## 말투 규칙

규칙 전문은 `.claude/handoff/assets/cozy-copy-world/glossary.md`. 요점:
- 문장은 해요체(~어요 · ~예요/이에요 · 부탁은 ~해 주세요). 한다체·합쇼체도 해요체로.
- 변수 뒤에 이다가 오는 자리는 받침을 몰라 문장을 고쳐 고정 글자 뒤에 붙였다(`(이)` 표기 없음). `flow-logic.js phaseLine` 은 원래 받침을 가린다.
- 2인칭 「네 · 너 · 네가」 는 뺐다(「네 답을 기다려」 → 「답을 기다려요」, 「너한테 물어」 → 「나에게 물어요」).
- 단추·탭·칩은 명사·짧은 동사구. 문장이던 단추는 줄였다: 「확인했어 · 알겠어」 → 「확인」, 「그렇게 고쳐 줘」 → 「그렇게 고치기」, 「내가 직접 볼게」 → 「직접 보기」, 「다른 걸로 할래」 → 「다른 걸로 하기」, 「다 고쳤어, 이어서 해 줘」 → 「다 고쳤으니 이어서 하기」, 승인 단추 「하지 마 · 이번만 지워 · 지우지 마 · 이번만 올려 · 올리지 마」 → 「하지 않기 · 이번만 지우기 · 지우지 않기 · 이번만 올리기 · 올리지 않기」(`notice-logic.js permVerbs`·`allowRole` 비교 글자와 `app.js` 승인 화면을 같이). 한도 칩은 「한도 알 수 없음」.
- 넣지 않은 것: 「~해 드릴게요」·「~하실 수 있어요」·「~하시겠어요」, 느낌표(옛 장면 이름표 「내 차례!」 도 뺐다), 이모지, 군말.
- 「검사를 못 했다」 문장은 「검사를 못 해서 멈췄어요 — 통과도 실패도 아니에요」 처럼 통과·실패가 아님을 그대로 남겼다(저장소 규칙 7).

### 요청 화면의 「기다리는 중」 세 번(5회차가 넘긴 것)

머리 상태 표시는 질문·승인·계획 모두 「답을 기다려요」, 그 아래 문장은 「AI가 이 일을 해도 되는지 물어요」(승인), 사람 옆 한 줄은 「…손을 들고 승인을 기다려요」. 「기다리」 가 세 번에서 두 번으로 줄었다. 계획 확인만 따로 부르던 「내 계획 확인을 기다리는 중」 은 머리에서 「답을 기다려요」 로 합쳤다(세션 화면 눈썹은 「계획 확인을 기다려요」 로 남음).

### 도장 아랫줄 「리뷰 룸」(4회차가 넘긴 것)

`sealDesk` 가 승인·계획이면 「리뷰 룸」 을 찍던 것을 질문과 같은 규칙(그 세션이 앉은 곳)으로 바꿨다. 새 사무실 장면에서 승인을 묻는 세션은 자기 자리에서 손을 든다. `clerkLine` 도 승인·계획에 앉은 곳을 붙인다(「요구분석팀 자리에서 손을 들고 승인을 기다려요 …」). 세션 안내판 「리뷰 룸 · 검토」(팀 승인을 기다리는 세션이 실제로 리뷰 룸에 앉음)와 팀 칸 title 의 「카페·리뷰 룸·완료」 는 장면에 그 방이 있어 그대로다.

### 지운 것

`post-logic.js` 의 `HERE` · `hereLine`(5회차에 화면에서 빠져 쓰는 곳이 없었다).
