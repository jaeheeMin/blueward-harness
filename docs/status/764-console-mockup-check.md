# #764 웹 콘솔 화면 치수를 시안 기준과 자동으로 대조하는 검사 (2026-11-07)

## 왜

세션이 바뀔 때마다 "시안과 똑같이" 를 눈대중으로 다시 판단해 이미 지적한 너비·배치 차이가 되풀이됐다. 이전 세션이 "대조 완료" 로 적은 G-09 를 숫자로 재니 오른쪽 끝·제목 블록·대화 판·오른쪽 칸·할 일 카드가 어긋나 있었다.

**규칙: "시안 대조 완료" 는 이 검사 통과로만 기록한다.** 눈으로 본 것, 일부 요소만 잰 것, 검사를 못 돌린 것은 완료가 아니다. 검사 불능(종료 코드 2)은 통과도 위반도 아니다. 사용법은 `docs/design/web-console.md` 9a.

## 추가: 배경·로고·색 (같은 날)

- 배경: 페이지 배경이 창 높이 끝까지 덮는지(콘솔 쪽만 판정). 로고: `naturalWidth > 0` 과 크기·위치. 색: 주요 요소의 `background-color`·`color` 정확히 일치(예외는 `screen_config.COLOR_EXCEPTIONS`).
- 기준은 시안 사본 `_blob/` 의 진짜 로고·글꼴로 다시 뽑았다(전에 콘솔 로고·글꼴로 바꿔 끼우던 처리는 없앰, IBM Plex Mono 만 JetBrains Mono 로 대신).
- 글자색 예외(`screen_config.COLOR_EXCEPTIONS`, 사용자 결정 "11-07 이전: 글자 대비 4.5:1 위해 콘솔 값 유지(#722)"): 값 쌍으로만 적용한다 - 기본 글자색 시안 `rgb(255,255,255)` / 콘솔 `rgb(243,250,248)`, `--lmuted` 시안 `#6d7775` / 콘솔 `#55625f`. 다른 색으로 바뀌면 그대로 실패한다. 배경색·테두리색에는 예외가 없다.
- main(6e71e93) 결과: 로고·배경 덮기·색(배경, 예외 뺀 글자색)은 8개 화면 모두 통과. 8개 화면 모두 실패는 그대로이고 건수는 G-04 14 / G-05 14 / G-06 12 / G-09 44 / G-10 18 / G-12 24 / G-13 16 / G-15 14 로, 모두 치수·위치 차이다.

## 기대값 정정 (S·N·D 고친 코드로 돌린 뒤)

- G-09: 지금 단계 알약은 시안대로 '올리기', '올리고 검토 요청' 은 할 일 카드 단추 글자로 검사. G-10: 순서 알약 기대를 빼고 숫자 띠 '3 / 3 승인 기다림'·사이드바 '승인 기다림 · PR #'·안내 '합쳐지면 여기와 홈에서 알려 줄게' 를 기대로. G-13: 머리글 '시작 점검 · 자동'.
- 대응표: opt ↔ 콘솔 `.kind`, G-04 tile ↔ `.tile2`(세션 화면은 `.docs-list`).
- eyebrow.y -5 는 검사 쪽 착시였다. 시안은 인라인 span(높이 13, 줄 상자 안에서 아래로 5px), 콘솔은 블록(높이 21)이라 상자 위치가 달랐을 뿐 글자 줄 세로 가운데는 같다(약 1px). 이제 글자 줄 세로 가운데(`tcy`)로 견준다.

## 리뷰 지적 반영

- 검사 불능은 항상 종료 코드 2: 시험 콘솔 도우미가 `ConsoleUnavailable`(포트 사용 중·서버 안 뜸·로그인 주소 못 받음)을 던지고 `run()` 이 2 로 끝낸다. `extract_baseline` 도 못 뽑으면 2. 콘솔 값을 못 잰 항목(시안엔 값이 있음)은 "측정 못 함"으로 따로 보고하고(통과도 위반도 아님) 실패가 없으면 2.
- `cdp.Browser.__enter__` 가 중간에 실패하면 프로세스·임시 프로필을 지우고 다시 던진다.
- `stop_server`: 포트 4873·4874 는 거부. pid 파일의 pid 는 명령줄에 이번에 띄울 때 넘긴 토큰(`--run-token`)이 있을 때만 끄고, 아니면 건드리지 않고 검사 불능.

## 남은 것

- 화면 코드 수정(#762·#763)은 이 작업 범위 밖이다. 고친 뒤 위 명령이 8개 화면 통과해야 "대조 완료" 로 적는다.
- 상태 만들기가 있는 화면은 8개뿐이다. 나머지 시안(G-01~03·07·08·11·14·16~24)은 기준만 저장돼 있고, `fake_console/screens.py` 에 함수를 더하면 대조에 넣을 수 있다(`--list` 로 확인).
- 화면 구조 자체가 시안과 다른 곳은 요소 대응으로 못 잰다(예: G-15 시안은 한 장 화면, 콘솔 `/docs` 는 목록 + 미리보기 두 칸이라 `.comp` 는 건너뜀).
- gh·claude 는 흉내라 진짜 GitHub 의 검사 이름·승인 수는 못 본다.
