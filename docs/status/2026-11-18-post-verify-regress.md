## 고친 것
1. **접힌 세션 칸 `내가 할 일` 숫자가 펼친 목록 `할 일` 과 다름**(`app.js` `renderRail`, Post 분기). 390 은 세션 목록이 늘 접혀 있는데, 접힌 칸은 Sauce 처럼 내 차례 요청 수(8)를 보였고 펼친 목록 걸러보기는 `할 일 10`(내 차례 + 막힘 + 확인 못 함, 세션 수 — post-logic 이 일부러 「내 차례」와 이름을 가른 묶음)이었다. 요청이 다 처리되고 내 차례 세션만 남으면 접힌 칸은 0, 오늘 뱃지는 7이었다. Post 는 펼친 목록과 같은 계산(`filterMatch('turn', stateOf(…))`)으로 센다. 숫자를 누르면 요청이 있으면 첫 요청, 없으면 첫 할 일 세션으로 간다. 1440 에서 접어도 같은 숫자(10→10, 9→9).
2. **좁은 화면에서 스크롤하면 말풍선·도장이 위 메뉴줄을 덮음**(`theme-post.css`). 390 에서 메뉴줄(`.prail`)은 위에 붙어 있고 z-index 5 인데, 머리 줄 말풍선(`.nb-bubble`, app.css z 40)과 요청 도장(`.po-seal`, z 6)이 그보다 높아 스크롤하면 `새 작업`·`세션`·`파이프라인`… 글자 위로 지나갔다(요청 화면 본문 머리에서 재현). 메뉴줄을 45 로(대화상자 50·알림 창 60 아래). 고친 뒤 스크롤 60·120·200 에서 메뉴줄 아래로 지나감, `elementFromPoint` 가 메뉴 칸.
3. **작업 폴더가 없어진 세션의 갈래 고르기 칸이 `일 목록: 고른 작업 폴더가 아니야.`**(`flow-ui.js` `drawPicker`, Post 분기). 서버는 실제로 있는 세션 폴더를 늘 아는 폴더로 치므로, 세션 폴더로 403 이면 폴더가 없어진 것이다. Post 는 `일 목록: 이 세션의 작업 폴더가 없어져서(지운 폴더 등) 일을 고를 수 없어.` — 산출물 칸·/docs 의 같은 경우 문구와 맞춤. 회귀는 아니다(11-02 코드).
4. **팀 기록 못 읽은 프로젝트 줄에 `확인 못 함` 두 번**(`trouble.js`, Post 분기): `? 확인 못 함 · projC · 확인 못 함 — …` → `? 확인 못 함 · projC — …`.

넷 다 3회차 뒤 회귀는 아니고(1·2 는 #1028, 3 은 11-02, 4 는 11-08 코드) 이번 훑기에서 처음 짚었다. 고친 뒤 라이트·다크 × 1440·390 에서 같은 화면을 다시 찍었다(넘침 0, 콘솔 0).

시험: `test_web_console_ui.py` 끝 `test_post_regress_sweep_fixes`(원문, Sauce 경로 그대로인지 포함, z-index 는 메뉴줄 > 말풍선·도장, 메뉴줄 < 대화상자·알림 창·연결 띠를 숫자로 비교).

독립 리뷰(sonnet, 읽기 전용): 확실한 결함 없음. 반영 — 연결 끊김 띠가 메뉴줄 뒤에 숨는 것(위), 시험을 숫자 비교·블록 찾기로 단단히. 반영 안 함 — 새 작업 화면의 `진행 순서`·`일 갈래` 칸도 같은 403 문구를 쓰지만 거기서는 사용자가 고른 폴더라 「고른 작업 폴더가 아니야」가 맞는 말이다. 추측(미확인): 폴더가 있는데 권한·떨어진 드라이브로 `isdir` 이 거짓이면 「없어졌다」로 말한다(서버도 같은 이유로 문서 목록 409 「폴더가 없어」).

## 결함 아님(확인)
- 알림 창 제목 `알림` 둘레의 굵은 테두리: 시험 스크립트가 JS 로 단추를 눌러 `:focus-visible` 이 켜진 것. 실제 마우스 클릭으로 열면 `:focus-visible` false, 테두리 없음.
- `/s/x1` 제목 `이름 없는 세션 · projC`, 같은 세션 대화에 같은 말 여러 번, 팀 기록 `ADMIN`: 시험 세계가 요청만 쏜 세션·같은 세션에 요청을 다시 쏜 것·가짜 gh 출력.
- 시간이 지나며 오늘 뱃지·일하는 중 수가 바뀜: 가짜 세션이 마지막 활동 뒤 `일하는 중` → `쉬는 중`·내 차례로 내려간다(3회차와 같음). 찍을 때마다 같은 순간의 숫자끼리는 맞았다.
