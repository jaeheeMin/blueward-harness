# #795 기록 화면: 올리기가 잠긴 이유와 댓글 종류 기본값

## 한 일

- `static/trouble.js`
  - 새 기록: 올리기가 잠기면 단추 옆(기존 `tb-note125` 줄)에 비어 있는 칸(프로젝트·단계·제목·증상·해결 방법)이나 "비밀번호처럼 보이는 줄을 지워 줘" 를 보인다. 단계는 처음에 `개발` 로 골라 둔다.
  - 한 건: 댓글 종류 기본(해결 후보)을 올리기 옆 글("'해결 후보' 로 올라가. 다르면 위에서 골라 줘.")로 말한다. 글을 고르면 그 종류 이름으로 바뀐다.
  - 번호 표기를 "기록 번호 #15 · 프로젝트 PROJ" 로.
- `trouble.py`: 비밀 검사 거절 문구의 칸 이름을 쉬운 말로(`text` → 댓글, `title`·`symptom`·`cause`·`solution` → 제목·증상·원인·해결 방법).
- 새 안내 줄은 기존 클래스(`tb-note125`, `tb-hint`)만 쓴다. CSS 는 안 바꿨다. 비밀 줄 잠금은 그대로.
- 시험: `test_trouble_console.py` 에 화면(node) 확인과 칸 이름 시험을 더했다.
- plugin.json 0.10.214, `whats_new.json`, 길잡이 기록 문단.
