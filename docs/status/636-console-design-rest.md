## 헤더 프로젝트 이름

원인: `projectOf()` 가 세션 화면이 아니면 "가장 위(내 차례 먼저) 세션" 의 저장소 이름을 썼다. 새 작업 화면은 사용자가 고른 작업 폴더(`draft.cwd`)가 따로 있는데 그걸 보지 않아서, 가장 위 세션이 다른 저장소(예: templete-func)면 그 이름이 나왔다. 고침: 새 작업은 고른 작업 폴더(끝 두 칸 `public-cloud/work2`), 세션·질문·승인은 그 세션, 그 밖 화면은 열린 세션의 프로젝트가 하나뿐일 때만 보이고 여럿이면 비운다. 새 작업 화면이 폴더를 바꿀 때 헤더를 다시 그린다.

## 기억(context) % 조사 (구현 안 함 — 따로 이슈로)

결론: **계산할 수 있다.** 단 한 가지 값(모델의 기억 창 크기)은 파일에 없다.

- 근거 파일: 세션 대화 기록 `~/.claude/projects/<작업 폴더를 -로 바꾼 이름>/<session_id>.jsonl`. 한 줄이 JSON 이고, `type: "assistant"` 줄의 `message.usage` 에 토큰 수가 있다(이 세션 파일에서 직접 확인: 181개 assistant 줄 모두에 있음).
- 필드: `message.usage.input_tokens` + `cache_creation_input_tokens` + `cache_read_input_tokens` = 그 응답을 만들 때 모델에 들어간 글 전체. **마지막 assistant 줄(`isSidechain` 이 아닌 것)의 합**이 지금 기억 사용량이다. 확인한 값: 2 + 340 + 241140 = 241,482 토큰. (`output_tokens` 는 더하지 않는다. 서브에이전트 줄은 `isSidechain: true`.)
- 모델: 같은 줄 `message.model` (예: `claude-opus-5-5`). 그런데 **창 크기(20만 / 100만 등)는 jsonl 어디에도 없다.** `[1m]` 같은 표시도 없었다. 그래서 %를 내려면 모델 → 창 크기 표를 콘솔이 들고 있거나(틀릴 수 있다), 모르면 "241k 토큰 사용" 처럼 토큰 수만 보이고 %는 "확인 못 함" 으로 둬야 한다.
- 서버가 파일 위치를 아는 법: 훅 입력에 `transcript_path` 가 있다(`docs/status/601-subagent-edit-guard.md` 에 PostToolUse·SubagentStart 입력 목록). 지금 `console/*.py` 는 이 값을 저장하지 않는다. 훅 이벤트(`hooks_api.event`)에서 세션에 `transcriptPath` 를 적어 두면 된다. 터미널 세션도 같은 훅이라 똑같이 얻는다.
- 구현 때 주의: 파일은 수 MB 로 커지므로(이 세션 4.7MB) 처음부터 읽지 말고 끝에서 거꾸로 읽어 마지막 assistant 줄만 찾는다. 읽기 실패·usage 없음은 "확인 못 함". 대화 압축(`PreCompact`) 뒤에는 값이 줄어드니 항상 마지막 줄 기준.
- 이 값이 생기면 바꿀 곳: 세션 목록 링 `?`(기억 사용량 확인 못 함), 홈 표 "기억" 열, 시안 18 배너(90% 이상), 시안 12 handoff 카드의 기억 % 문구, 숫자 띠 "기억" 칸.
