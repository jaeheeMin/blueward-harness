## 고친 것
1. **작업 폴더가 지워진 뒤 시작**(`app.js` `begin`·`folderCheck`): 시작이 400 으로 거절되면 `/api/folders/validate` 로 까닭을 보고, 폴더 탓이면 쓰기 화면으로 돌아가 폴더 목록을 열고 `고른 작업 폴더를 쓸 수 없어: … 다른 폴더를 골라 줘.` 를 보인다(경로 입력칸에 초점). 폴더 탓이 아니면 예전 실패 화면. Post 만.
2. **서버에 닿지 못한 시작**: 실패 화면 제목이 `콘솔 서버에 연결하지 못했어`(Post 만).
3. **키보드 초점**(Post 만): 쓰기·분석·실패·확인 단계가 바뀌면 제목(`#new-title`, `tabindex=-1`, 윤곽선 없음)으로 초점. 시작 오류·글 비어 있음·폴더 창 취소·경로 확인 뒤에는 누른 칸으로 되돌림(`start-go`·`brief`·`folder-browse`·`custom`).
4. **첨부가 서버에서 거절되면**(400·413, Post 만) 끝에 `첨부를 바꾸려면 "다른 걸로 할래" 로 돌아가서 빼 줘.`
5. **아주 긴 폴더 이름**(`theme-post.css`): 제목·눈썹 `overflow-wrap: anywhere`, 위쪽 줄은 이름만 줄고 알림·테마 단추는 그대로(`flex-shrink: 0`).
- 시험: `test_web_console_ui.py` 끝에 `test_post_new_task_extra_cases_X1` 덧붙임.

## 독립 리뷰(서브에이전트 sonnet, 읽기 전용) 반영
- 시작 오류 뒤 초점을 무조건 단추로 되돌려, 기다리는 사이 다른 칸으로 옮긴 초점을 뺏던 것 → 초점이 문서 맨 위(`body`)일 때만 되돌림.
- `flex-shrink: 0` 이 한도 칩 묶음의 줄바꿈까지 막아 390 에서 넘칠 수 있다는 의심 → `.ptop-lim` 은 뺌(한도 96%·83% 칩 + 200자 폴더 이름으로 390·1440 가로 넘침 0 확인).
- 분석이 끝났을 때 머리줄 등에 있던 초점을 가로채는 것 → `body` 일 때만 제목으로 옮김.
- 400 뒤 폴더 확인이 늦게 오면 그사이 다시 시작한 요청을 덮을 수 있음 → 시작마다 번호(`beginRun`)를 붙여 늦은 답은 버림.

## 고치지 않은 것
- 같은 파일 두 번·글 밖 끌어놓기: 공유 `attach.js`(Sauce 도 바뀜). 판정 대기.
- 분석 도중 「요청 고치기」를 정확히 폴링 응답이 도착하는 순간에 누르면 확인 화면으로 튈 수 있다(`poll` 콜백이 단계를 안 본다). 응답 대기가 몇 ms 라 재현하지 못했고 이론상만이라 손대지 않았다.
- 초점 단계 이동은 세션 화면(`/s/…`)으로 넘어간 뒤에는 이어지지 않는다(새 작업 화면 밖).
- 200자짜리 폴더 이름은 폴더 목록 줄이 9줄로 길어진다(넘치진 않음, 극단 입력이라 그대로).
- 시작 뒤 세션 화면 이동 실패 안내(id 를 못 받으면 링크를 보이는 줄)는 서버가 항상 id 를 줘서 만들어 볼 수 없었다. 코드 읽기로만 확인.
- 서버를 다시 띄우면 열린 화면이 401 이라 「분석 기록 없음(404)」 분기에 닿지 않는다(그 분기는 만들지 않았다).
