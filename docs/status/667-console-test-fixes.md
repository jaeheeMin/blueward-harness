# #667 웹 콘솔 기능 시험에서 찾은 작은 문제 고치기

확정 디자인(#636) 병합 뒤 기능 시험(2026-11-04)에서 나온 세 가지. 플러그인 0.10.171(0.10.169·0.10.170 은 다른 열린 PR 이 쓴다).

## 한 일

- 홈 내 차례 카드(`flow-ui.js` homeView): 가장 오래 기다린(`updatedAt` 이 가장 작은) 한 건만 카드로 두고, 나머지는 카드 아래 "외 n건" 알약(`.calls-rest`)으로 펼치고 접는다. 브라우저 기본 위젯·details 를 쓰지 않는다. 펼침 상태는 홈 화면 객체에만 있다.
- 새 작업 기본 폴더(`app.js` newView `defaultFolder`): ① `/new?from=<세션 id>` 면 그 세션의 폴더(세션 목록에 없으면 `GET /api/sessions/<id>` 로 따로 읽음) ② 아니면 `GET /api/folders/last`(서버가 기억한 마지막으로 작업을 시작한 폴더) ③ 둘 다 없으면 기본값 없이 폴더 목록을 펼친다. 옛 규칙(최근 폴더 첫 줄 = 이 PC 의 가장 최근 세션 폴더)은 없앴다. 최근 폴더 목록(고르는 후보)은 그대로.
- 세션 화면 진입: 세션·질문 화면에서는 헤더 `새 작업`, 목록 아래 `+ 새 세션`, 접힌 레일 `+` 가 `/new?from=<세션 id>` 로 간다(`newHref`). 질문 화면은 그 요청의 세션.
- 서버(`server.py`): 작업을 시작(`POST /api/new/<id>/start`)할 때 폴더를 상태 폴더 아래 `last-folder.json` 에 쓴다(첫 실행 표시 `first-run.json` 과 같은 방식, 상태 폴더가 없는 실행은 메모리). 읽을 때 지금 없는 폴더·깨진 파일은 없는 것으로 본다.
- 길잡이 레일 판 표시를 0.10.171 / 2026-11-04 로, 콘솔 설명(홈 카드·새 작업 기본 폴더)과 `docs/design/web-console.md` 를 맞춤.

## 시험

- `test_web_console_ui.py`: 홈 카드 묶기 DOM(여러 건 → 카드 1 + 외 n건, 펼침·접힘, 한 건이면 알약 없음), 기본 폴더 우선순위 3갈래와 진입 링크. 스모크 도우미(`console_ui_smoke.js`)가 `?쿼리` 있는 경로를 받게 함. 기존 헤더 프로젝트 시험은 마지막 폴더를 주도록 고침.
- `test_web_console.py`: 시작하면 마지막 폴더가 상태 폴더에 저장되고, 없어진 폴더·깨진 파일은 무시.
