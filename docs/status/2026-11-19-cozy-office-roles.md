# Cozy Office 색을 역할로 다시 나누기 + 알림 말풍선 (2026-11-19, 갈래 B 1회차)

브랜치 `post/cozy-roles`(worktree `cozy-roles`). 이슈·PR·판 올리기 없이 이 갈래에 커밋만 했다(합류는 뒤 회차).

## 왜
Cozy Office(Post)는 Sauce 의 변수(`--accent`·`--attn`·`--st-*`)를 값만 덮어 썼다. 그래서 강조색 빨강이
주 버튼·고른 칸·결재 도장·배지에 다 쓰였고(빨강인데 확인 버튼), 노랑이 「답을 기다림」 과 경고에 같이 쓰였다.
색을 뜻(역할)마다 하나로 정하고, 부품은 역할 색만 쓰게 바꿨다. Sauce 의 모양은 그대로다(`app.css` 는 안 고쳤다).

## 역할 표 (역할 → 토큰 → 쓰는 부품)
토큰은 `theme-post.css` 맨 위 뿌리 블록에 있다. 역할마다 글자(`--x`) · 채움(`--x-fill` + 위 글자 `--on-x`) ·
옅은 바탕(`--x-bg`) · 선(`--x-line`)이 한 벌이다. 값은 밝게 / 어둡게.

| 역할 | 뜻 | 토큰 (밝게 / 어둡게) | 쓰는 부품 |
|---|---|---|---|
| 주 | 주 버튼, 지금 고른 것 | `--pri` #24304A / #F3EEE3, `--on-pri`, `--pri-hover`, `--pri-soft` | `.btn.primary` · `.pill.dark` · `.pill.acc` · 새 작업(`.prail-new`) · 고른 칩·보기(`[aria-pressed=true]`) · 켠 스위치 · 체크 · 프로젝트 점 |
| 보조 | 그 밖의 버튼 | `--btn-face` · `--btn-edge` · `--btn-drop` · `--btn-lift` | `.btn` · `.pill.line` · `.pill.ghost` · 테마 단추 · 알림 단추(`.nb-btn`) · 팝업 이전·다음·닫기 |
| 알림 | 내 답을 기다림, 눌러서 갈 곳 | `--ask` #2F5FA6 / #9CC0F5, `--ask-fill`, `--ask-bg`, `--ask-line` | 「오늘」 배지(`.prail-badge`) · 답 기다림 표시(`.po-st-turn`·`.po-stc-turn`·`.po-ss`) · 「내 차례 N」 숫자 · 맨 앞 카드 점선 · 메모 이름표 · 세션 머리 줄 · 질문 카드(`.call`·`.approval-card`) · 사이드 링 · 파이프라인 카드 · 본문 링크 · 말풍선(질문) · 새 판(조용한 꼴: 말풍선은 종이 바탕에 파란 아이콘, 배지·팝업 이름표·판 옆 점 `.ptop-vdot` 은 파랑) |
| 경고 | 조심, 승인 전 확인 | `--warn` #8A4B00 / #F2B24C, `--warn-fill` #FFD66B, `--warn-bg`, `--warn-line` | 기억 배너(`.banner`) · 이름표(`.tag`·`.tagx.warn`·`.chip2.warn`) · 한도 경고 · 승인·계획을 기다리는 세션의 표시(`data-color-role="warn"`) · 말풍선(승인 요청·계획 확인) |
| 오류 | 실패, 막힘, 위험한 일 | `--err` #A82A20 / #FF9A90, `--err-fill` #C2372C, `--err-bg`, `--err-line` | 막힘 표시(`.po-st-blocked`) · PR 검사 실패 · API 오류 카드 · 실패 알림 줄(`role=alert`) · `.nb-err` · 실패 칩 · 지우는 일의 허락 단추(`.pill[data-color-role="err"]`) · 말풍선(검사 실패·막힘·오류) |
| 승인/성공 | 승인, 끝남, 통과 | `--ok` #1F5C42 / #8FD9B4, `--ok-fill` #2F7D5B, `--ok-bg`, `--ok-line` | 허락·진행 단추(`.pill[data-color-role="ok"]`) · 결재란 끝난 칸 · 도장(`.po-seal`. 반송은 중립) · 통과 칩 · 끝난 세션 머리 줄 · 말풍선(합쳐짐) |
| 확인 못 함 | 통과도 위반도 아님 | `--unk` #5A47A8 / #BDB0F5, `--unk-bg`, `--unk-line` (점선) | 확인 못 함 카드·머리 줄 · 말풍선(확인하지 못했어요) |
| 중립 | 쉬는 중, 남의 승인을 기다림 | `--muted` · `--sec` · `--paper` | 쉬는 세션 · 승인 기다림 표시(실선 테두리. 점선은 확인 못 함뿐) · 반송 도장 |
| 초점 | 키보드 초점 | `--focus` #3D6FB6 / #8DB4F0 | `:focus-visible` 2.5px 테두리 |
| 로고 | 브랜드 표시만 | `--brand` #C73E31 / #F0685A | `.prail-mark` 한 곳 |

- 옛 변수는 역할로 이었다: `--accent`·`--btn`·`--st-now`·`--accent-fill` → 주, `--attn`·`--st-turn` → 경고,
  `--st-fail`·`--danger`·`--fail-fill` → 오류, `--st-done`·`--accent2`·`--done-fill` → 성공. 어두운 모드는 역할 값만 바꾼다.
- 같은 일은 어디서나 같은 색이다: 말풍선 · 팝업 · 오늘 카드 · 메모 · 세션 목록 · 세션 머리 줄 · 파이프라인이
  `data-color-role`(ask · warn · err · ok · unk · info) 하나로 맞는다(`post-home.js` `toneOf`, `app.js` `turnTone`).
  속성 이름이 `data-tone` 이 아닌 까닭: 시험 `test_no_theme_or_design_switch_left` 가 그 글자를 막는다.
- 버튼 말씨는 장면 버튼(`.of-btn`)과 같다: 남색 선 1.5px + 아래 단단한 그림자, 올리면 뜨고 누르면 내려간다.
- 글자 대비는 시험이 잰다(역할 글자색 × 바탕 4종, 채움 위 글자. 밝게·어둡게 모두 4.5:1 이상).

## 말풍선
- Cozy Office: 종류 색의 버튼 한 줄 — 아이콘 · 이름표 · 내용 · `+N`(좁은 폭에서는 숨김) · `›` · 「나중에」.
  올리면 뜨고 누르면 내려가며, 밑줄은 없다. `≡` 단추의 배지는 알림 건수이고 가장 급한 알림의 색이다.
- **✕ 가 실제로 하던 일**(`dismissBubble`): 그 알림 id 를 `sessionStorage` `bh-nb-dismissed` 에 적어 말풍선에서만 접는다.
  알림 목록(`≡`)과 배지에는 남고, 다음 알림이 이어서 뜨고, 탭을 닫으면 잊는다. 지우기도 읽음 처리도 아니라서
  Cozy Office 에서는 글자 단추 「나중에」 로 바꿨고, 두 테마 모두 이름표를 「이 알림 나중에 보기 — 말풍선에서만 접어요. 알림 목록(≡)에는 남아 있어요」 로 고쳤다.
- 말풍선·팝업 문구는 해요체로 바꿨고 「내 차례」 는 쓰지 않는다. 한 줄 형식은 `종류 · 세션 · 내용 외 N건`(두 테마 같음).
- Cozy Office 팝업: 질문이 하나고 제목이 이미 그 질문이면 같은 줄을 두 번 쓰지 않는다.

## 독립 리뷰(sonnet, 읽기 전용) 반영
- API 오류로 멈춘 세션의 머리 줄이 파랑(끝난 세션이면 초록)이었다 → 오류 빨강(`eyebrowFor` 셋째 값 → `data-color-role="err"`).
- 접힌 세션 목록의 동그라미(`.rail-ring.turn`)와 차분 목록(`.po-ml-turn`)이 승인·검사 실패여도 파랑이었다 → `turnTone` 으로 노랑·빨강.
- 노란 띠 안 「다시 연결하지 못했어」 글자(`.banner .mcp-err`)가 4.1:1 이었다 → `#8A4B00`(4.9:1). 시험이 값이 아니라 대비를 잰다.
- 새 판이 자리마다 달랐다(말풍선 종이 · 배지 회색 · 팝업·판 옆 점 파랑) → 「알림의 조용한 꼴」 하나로 맞췄다(배지를 파랑으로).
- 시험: 약해진 띠 단언을 한 규칙 정규식으로 되돌리고, 늘 참이던 단언을 빼고, 올렸을 때 채움 4개의 대비와 Post 분기 실행 시험을 더했다.
- 고친 세 곳은 밝게 1440 에서 계산된 색으로 다시 확인했다(머리 줄 `rgb(168,42,32)`, 동그라미·차분 목록 노랑·빨강·파랑).

반영하지 않고 둔 판단:
- `+N`·「외 N건」 은 「나중에」 로 접은 알림도 센다. 접은 알림도 목록(≡)에 남아 있어서 목록 건수와 맞춘 것이다.
- 허락 단추는 지우는 일만 빨강이고, 올리기 같은 그 밖의 되돌릴 수 없는 일은 초록(승인)이다. 되돌릴 수 없다는 경고는 위의 노란 「확인 필요」 이름표가 맡는다.
- 방금 처리해 도장이 찍힌 카드는 사라지기 전 잠깐 원래 종류 색(승인이면 노랑 점선)으로 남는다. 이름표는 요청의 종류, 도장은 결과를 말한다.

## 남긴 것 (이 회차 범위 밖)
- 장면 번들(`static/post/office/`)의 「?」 말풍선·숫자 배지는 빨강 그대로다. 합류 회차가 알림 파랑(`--ask-fill`)에 맞춰야 한다.
- `api-notice.js` 본문은 반말 그대로라 오류 팝업에서 해요체 제목과 섞인다. 문구 회차 몫.
- `trouble.js` 의 `.tag`(✕ · ?)는 파일이 범위 밖이라 노랑 그대로다.
- 세션 목록의 「내 차례」 · 메모의 「내 차례 1/8」 · 「내 답이 필요해」 같은 기존 문구는 안 바꿨다(문구 회차 몫).
- `≡` 배지(전체 알림 수)와 「오늘」 배지(답을 기다리는 수)가 다른 수다. 요약 중복 회차 몫.
- 파일 형식 배지(`.ext-*`)는 Office 고유색 예외로 뒀다. `.attach-btn` · `.tool` 칩은 베이지 그대로다.
- 올렸을 때 채움 4개(`--bub-hover`)와 장면 이름표(`.po-tag`. 장면은 밝게 고정)는 값으로 적혀 있다.
