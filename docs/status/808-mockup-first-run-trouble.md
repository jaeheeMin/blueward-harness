## 확인

- 상태를 만들다 고친 것: G-24 세션이 처음엔 PR #812 와 연결되지 않아(쓰기 단계가 안 끝나 `flowPr` 가 비어 있었다) 콘솔이 노랑 카드를 더 띄웠다 — 상태 만들기 쪽 잘못이었다.

- 2026-11-09 #809 위(main = #801 병합 뒤 + #794·#796·#809)에서 준비된 16개 화면(G-01~06·09·10·12·13·15·20~24) 모두 1440·1280 통과. PC 메모리가 빠듯해 전체를 한 번에 돌리면 멈춰서, 2~4 화면씩 나눠 돌렸다.
