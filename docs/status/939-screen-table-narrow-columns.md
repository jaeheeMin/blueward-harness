# #939 화면 그림 결과 테이블 열이 많으면 열 너비를 1칸으로

## 배경

개발사양서 화면 그림은 결과 테이블 열을 `칸_수.열`(기본 2칸) 너비로 그려, public-cloud 지도의 영역 C7:S14(17칸)에서는
8열까지만 들어가고 9열부터 산출을 거부했다.

## 바꾼 것

- `checker/screen_draw.py` `draw`: `layout` 결과가 넘치고 결과 테이블이 있고 `칸_수.열` > 1 이면 열 너비 1칸으로 다시 `layout`.
  들어가면 그 배치를 쓰고 `warn` 으로 알린다. 그래도 넘치면 거부(문구에 "실제 화면 캡처를 쓴다" 추가). 넘치지 않는 표는
  이 길을 타지 않아 이전과 같다. 중간 값(3칸 → 2칸)은 시도하지 않는다(단순하게 1칸만).
- `checker/export.py`: `draw` 에 `warn` 을 넘겨 `warnings` 에 "화면 1 결과 테이블 열이 많아(N개) 열 너비를 1칸으로 줄였다" 를 낸다.
- 지난 판 비교(`screen_diff.merge`)는 삭제 항목을 합친 목록을 `layout` 에 넘기므로 넘침 판정도 그 목록 기준이다.
- 저장 훅·PR 의 `form_columns` 는 구조 검사(`offenders`)만 하고 영역 초과는 산출·`--check` 에서만 보므로 같은 `draw` 를 쓴다.
- 지도 키는 늘리지 않았다(자동 동작). 스킬 문서(`form-map.md`·`spec/SKILL.md`), 길잡이, plugin.json 0.10.279, whats_new.json 갱신.

## 시험

- `checker/tests/test_screen_draw.py`: 8열(2칸·경고 없음·셀 좌표), 9열(1칸·경고·액션 재정렬), 17열, 18열 거부, 칸_수.열 3 에서 넘침 → 1칸,
  칸_수.열 1 이면 거부, 좁혀도 행이 넘치면 거부. 기존 9열 거부 시험은 18열로 바꿈.
- `checker/tests/test_screen_diff.py`: 열 추가로 합친 목록이 10열이 되는 변경 표시.
