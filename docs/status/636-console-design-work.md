# #636 웹 콘솔 디자인 "Sauce" 2차: 작업 화면

3덩어리 중 둘째. 세션 화면·질문·승인·새 작업(05~10, 12)을 시안대로 옮겼다. 홈·앱 틀·토큰은 첫 덩어리(`636-console-design-base.md`)를 그대로 쓴다. 설정 화면은 다음 덩어리.

## 한 일

- `flow-logic.js`: 숫자 띠(`sessionStrip`), 진행 %(`progressOf`), 이슈 번호(`issueOf`), REQ 번호(`reqIds`), 검토 요청 줄(`prLines`) 순수 함수.
- `flow-ui.js`: `flowPanel({compact})`(세션 화면은 제목 아래 알약이 순서를 보이므로 갈래 이름·막대를 뺀다. 지금 할 일은 어두운 "네 차례" 카드, 끝나면 handoff 카드), `prCard`(검토 요청 카드), `flowPreview`("이렇게 진행돼" 단계 칸), 갈래 고르기가 단계 칸을 보임, 만든 산출물 칸을 시안 종이 모양으로.
- `app.js`: `sessionView` 를 제목 블록 · 순서 알약 · 숫자 띠 · 밝은 대화 판(결과 보고 · 순서 체크리스트 · 검토 요청 · 내가 보낸 말 · 네 차례 · 작업 멈추기 · 입력창) · 오른쪽 산출물로 다시 짬. `requestView` 질문은 `.q` 카드 + 알약 보기, 승인은 시안 17 "확인 필요" 카드. `newView` 는 종류 버튼 → 입력 → 참고 파일 안내 → 이렇게 진행돼 → 접힌 고급 설정 → 작업 시작, 확인 화면은 시안 06. 요청이 뒤늦게 오면 세션 화면도 다시 그림.
- `app.css`: 위 화면 스타일 추가, 쓰지 않는 옛 규칙(타일·eyebrow·report 박스·q-block 등) 삭제. `plugin.json` 0.10.167(0.10.166 은 다른 PR 이 씀).
- 시험: `test_web_console_ui.py` 에 숫자 띠·PR 카드·compact 패널·가짜 DOM 에서 실제로 화면을 그려 보는 스모크(`console_ui_smoke.js`) 추가, `test_web_console.py` 의 승인 화면 시험을 새 규칙에 맞춤.

## 데이터가 없어 비운 칸

- 숫자 띠: 요구사항 · 개발 번호는 끝난 갈래의 다음 갈래 옵션에 REQ 가 있을 때만, 작업 기록은 브랜치 이름에 번호가 있을 때만, 검토 요청은 갈래 데이터(없으면 "PR 아직", 읽지 못했으면 "확인 못 함"). 갈래가 없으면 단계 칸만 "정해진 갈래 없음".
- AI 진행 %: 서버가 주지 않아 `끝난 단계 ÷ 전체 단계` 로 계산하고 칸의 설명(title)에 근거를 적었다. 끝난 갈래는 "끝".
- 내가 처음 한 말(.me)은 세션 데이터에 없다. 이 화면에서 보낸 말만 보인다.
