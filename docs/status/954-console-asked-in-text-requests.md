# #954 물음표 없이 답을 달라고 끝난 보고를 답 기다림으로 못 알아봄 (0.10.287)

## 배경
세션이 결과 보고 끝에 사용자 답을 기다리면 콘솔은 제목을 "내 답을 기다리는 듯해(추정)." 로 바꾼다(`askedInText`). 지금까지는 끝 줄이 물음표로 끝나는지만 봤다. 실사용 시험 B(11-14)에서 `/harness:spec` 이 "…라고 하시면 PR 을 만들겠습니다. 항목을 바꾸려면 알려 주세요. Spec 을 고친 다음에 올립니다." 로 멈췄는데 "쉬는 중" 으로 보였다.

## 한 것
| 파일 | 내용 |
|---|---|
| `plugins/harness/console/store.py` | `report_asks`: 끝 줄 물음표에 더해, 끝 3줄을 문장으로 나눈 뒤 끝 3문장 중 하나가 답을 기다리는 꼴이면 True. 문장마다(`_sentence_asks`) — 끝인사(`필요하면·궁금하면·언제든·더·다른 것·추가로`)가 들면 아님. 제안(`알려·말해·골라·정해·승인해·허락해·확인해 주(시)면`, `원하시면`, `말씀하시면`, `라고 하(시)면` 뒤 `…겠습니다·…게`)이나 기본값 예고(`없으면·괜찮으면 … 넘어갈게·진행할게·올릴게`)면 맞음. 요청(`알려·말해·말씀해·골라·정해·답해·선택해 주세요/줘`, `라고 해 줘`)은 앞에 조건절(`…면 `)이 있으면 허락 조건(`괜찮으면·좋으면·원하면·맞으면`)일 때만 맞음 |
| `docs/guide/harness-guide.html` | "글로 물어본 세션" 문단 |
| `checker/tests/test_web_console.py` | 끝맺음 표 48개(시험 B 원문, "화면" 명사 뒤 질문, 조건절 뒤 고르기, 끝인사·"…면 알려 줘" 조건절·"재시작하시면 …되겠습니다" 설명·"알려 줄게"·"확인해 주세요"·"알려 줘서 고마워"·앞쪽 문장의 요청) |

## 결정
- "확인해 주세요" 는 넣지 않았다. 답 없이 끝나는 부탁("PR 링크를 확인해 주세요")이 많아서다. "확인하시면 …겠습니다" 처럼 제안 꼴이면 잡힌다.
- 끝 3문장만 본다. 보고 앞쪽의 요청 뒤에 다른 일을 한참 보고했으면 답을 기다린다고 보지 않는다.
- 표시는 물음표 판정과 같은 "추정" 이다.
- 처음 판은 너무 넓었다(558 점검: 흔한 끝맺음 15개 중 7개 오탐). "문제가 생기면·끝나면·막히면 알려 줘" 같은 조건절 끝인사와 "재시작하시면 새 판이 적용되겠습니다" 같은 설명을 잡았고, `"진행" 이라고 해 줘` 는 놓쳤다. 조건절 요청은 허락 조건만 남기고, 제안은 답 동사로 좁히고, `라고 해 줘` 와 "없으면 …넘어갈게" 기본값 예고를 더했다.
- 둘째 점검: 조건절을 `[가-힣]+면 ` 으로 보아 "화면·측면" 같은 명사 뒤 질문("로그인 화면 문구를 어떻게 할지 정해 줘")을 놓쳤다. '면' 앞 글자가 명사 쪽(화·측·장·정·표·전·양·방·국·단·후·외·반·평·곡)이면 조건절로 보지 않는다(이·다·지·내 는 동사 활용과 겹쳐 넣지 않았다). 조건절 뒤라도 고르기·정하기 요청이 있거나 마지막 조건절과 요청 사이에 의문사(어느·어떤·어떻게·무엇)가 있으면 질문으로 보고(조건절 안의 의문사 "무슨 문제가 생기면 알려 줘" 는 세지 않는다 — 셋째 점검), 허락 조건 뒤 "나중에·아니면" 은 끝인사로 본다. 기본값 예고에 "맞으면" 을 더했다.
