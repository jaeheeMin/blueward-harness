# #451 길잡이에 Team 요금제·main ruleset 반영 (2026-10-25)

`docs/guide/harness-guide.html` 에서 "무료 요금제라 Merge 버튼을 못 잠근다" 는 설명을 걷어내고 현재 상태로 맞췄다.

- 검사 탭: 무료 요금제 callout 을 main ruleset 설명으로 교체. `merge-order` 는 필수 검사가 아니라 버튼을 안 잠근다고 표기.
- 승인·리뷰·병합 탭: 병합 순서 callout, 검사 표, 자동 병합 설명에 public-cloud 현황 추가. 옛 호출 파일 교체 안내는 기존 저장소 일반 안내로.
- 승인 없이 병합하려 할 때 그림: 필수 검사가 빨간 불이면 버튼이 안 열리고, 그래도(Owner 예외 등) 병합되면 사후 이슈.
- 주의사항 총정리, 용어 사전(main 보강, Ruleset·자동 병합 추가).
- 레일 아래 표기를 harness 0.10.112 로 맞춤.

확인하지 못해 쓰지 않은 것: ruleset 의 승인 수는 서버에 걸지 않았다는 사실 외의 세부 설정.
