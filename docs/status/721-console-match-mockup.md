# #721 웹 콘솔을 확정 시안(가 G-01~19)과 똑같이 맞추기

## 원인

앞 구현(#640·#644·#658)이 시안 CSS 를 옮기면서 시안에 없는 값을 더했다.

- 화면 전체 `html { zoom: 1.15 }` 와 `.page` 폭 상한(1040px, w-820/960/760): 같은 숫자도 시안보다 크고 좁게 그려졌다.
- 부품을 자기 식으로 다시 풀었다: 접근성을 이유로 단추·줄마다 `min-height: 44px`, 설정의 `.seg` 는 회색 트랙 안 작은 알약이 아니라 테두리 단추 묶음, 알림 스위치는 글 오른쪽 끝의 큰 스위치, 라디오는 44px 높이 단추에 설명 없음.

## 한 일

기준은 시안 CSS 한 벌(`mock.css`)이다. 보이는 크기·간격·글자·둥글기를 시안 숫자로 되돌렸다. 클릭 영역을 위한 `min-height` 는 시안에 없는 부품에서만 남겼다.

앞서 메인 세션이 고친 것: `html { zoom }` 삭제, 글자 크기 0.9 / 1 / 1.15(키 `bh-zoom`), `.page` 폭 상한 삭제, `.main` padding.

### 마크업을 바꾼 화면

- 설정(G-19): 스위치를 글 앞으로, 라디오에 시안 문구의 small 설명 3개(`ASK_OPTIONS.desc`), 알림 묶음은 `.stack`, 연결 상태 줄은 이름/값 색 바꿈. 제목 눈썹은 강조색 제거.
- 산출물(G-14): 눈썹 강조색 제거.
- 홈(G-11): 날짜 눈썹 강조색 제거.
- 새 작업(G-05): 첫 화면 눈썹만 기본색.

### 시안과 남은 차이

| 차이 | 이유 |
|---|---|

| 사이드바 `small.w`, `.strip .x.w` 앞의 `!` | 색만으로 구분하지 않으려는 표시 약속(#636) |

| 글자 줄바꿈 `word-break: keep-all` | 한글 읽기용. 시안에는 없음 |

## G-02 첫 실행 프로젝트 고르기

- 01 `시작하기` -> 02(`projectPickView`, 같은 `data-intro` 모드) -> `[이 프로젝트로]` -> 준비 필요 + 안내 미확인이면 `/new` 의 03, 아니면 홈(04). `[뒤로]` 는 01.
