# #790·#791 막힌 세션을 목록까지 올리고, 막힘 카드 뒤 할 일을 하나로

## 원인

- 훅이 막은 세션(✕ 막힘 · ? 확인 못 함)이 세션 화면 카드에서만 구분되고, 홈 표 · 사이드바 · 맨 위 띠 · "내 차례" 숫자에서는 "내 차례 · 작업 시작" 으로만 보였다.
- 막힘 카드 바로 아래 갈래 6개가 그대로 떠서 막힘을 먼저 풀지 새 일을 고를지 헷갈렸다. 직접 보기 뒤에는 안내가 없었다.
- 검사 원문의 "다음:" 줄과 "고치는 법" 이 같은 글이라 두 번 나왔다. 터미널 세션은 단추가 없는데 안내만 있었다.

## 한 일

- 서버: 세션 목록의 `lastBlock` 에 `open`(막힘 뒤에 내 말·AI 말이 아직 없음)을 더했다(`store.last_block_of`).
- 화면 판정 `BHLogic.blockOf`: 열린 막힘이면서 AI 가 일하는 중이 아니고 묻는 요청이 없을 때만 막힘. `counts` 는 막힘을 내 차례에서 빼 따로 센다. `open` 을 모르는 옛 서버는 막힘으로 치지 않는다.
- 홈: 표 상태 칸에 기존 칩 `tagx fail`/`tagx unk`, 표 위에 내 차례와 같은 모양의 카드(가서 보기). 사이드바 줄과 접힌 사이드바 점, 맨 위 띠 줄. 내 차례 띠 문장을 “제목” 세션에서 로 고쳤다(조사 문제).
- 세션 화면: 열린 막힘이 있으면 갈래 고르기 · 다음 단계 자리에 "고친 뒤 이어서" 안내. 직접 보기 뒤 다음 할 일 · [다 고쳤어, 이어서 해 줘] · [다시 고르기]. 원문에서 "다음:" 줄 제거. 터미널 세션 안내 문구와 잠긴 이유 줄 강조.

## 한계

- "풀렸다" 는 판정은 막힘 뒤에 내 말·AI 말이 이어졌는지로만 본다. 고쳐졌는지 검사를 다시 돌려 확인하지는 않는다.
- 터미널에서 연 세션은 대화를 내 말과 AI 마지막 답만 알아서, 그 사이 막힘이 풀렸어도 늦게 닫힐 수 있다.
- 시안(G-16)에 홈의 막힘 표시는 없다. 새로 더한 표시는 기존 칩 · 카드 클래스를 재사용했다.
