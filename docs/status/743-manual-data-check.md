# #743 매뉴얼 데이터로 화면 값 확인 (2026-11-09)

## 배경
매뉴얼 작업본에 적힌 값(넣는 값·나와야 할 결과)대로 화면이 나오는지 캡처 도중에 확인한다. 이 이슈는 조회 화면(데이터를 바꾸지 않는 동작)만 다룬다 — 저장·전기는 하지 않는다.

## 한 일
`capture.yaml` 화면 항목에 선택 키 `확인` 을 더했다.

- 형식: `{열, 값}`(그 열의 보이는 모든 행) · `{열, 행, 값}`(그 행 한 칸) · `{글자}`(화면 보이는 요소에 그 글자). 모르는 키·`열`+`글자`·`값` 없는 `열`·1 미만이거나 정수 아닌 `행`·빈 글은 `ListError`(종료 2). `값` 은 따옴표로 감싼 글자만 받는다(숫자·실수·bool 은 거부 — YAML 이 `0010` 을 8, `12:30` 을 750 으로 읽는다).
- 실행: 화면의 `준비` 와 대기가 끝난 뒤, 표시용 열 스크롤과 덮개 그리기 **앞**에서 돈다. 비교는 `trimLabel` 과 같은 정규화(`norm_text`) 뒤 정확히 같음.
- 결과: 항목마다 `맞음`/`다름`/`검사 불능`. `다름` 은 `실제`(다른 행 번호·값, 5개까지와 `다른 행 수`), `검사 불능` 은 `사유`(열 못 찾음·여럿·aria-colindex 없음·pop-in 열·보이는 행 0개·`행` 초과·읽기 실패).
- 전체: 확인 `검사 불능` 있음 → `unavailable`/2, 아니고 `다름` 있음 → `incomplete`/1, 기존 규칙과 합쳐 더 나쁜 쪽. 화면 자체가 검사 불능이면 확인 배열은 없다.
- `--check` 출력에 화면별 `확인 항목` 수.
- JS(`checker/manual_capture_js.py`): `columnValues(name)`, `hasText(s)`. 열 찾기는 `cellOf` 와 같은 `gridCells` 로 뽑아 함께 쓴다.
- 스킬 `/harness:manual` 에 `확인` 형식·결과 표·종료코드와 새 소절 "매뉴얼 데이터로 시험 목록 만들기"(Claude 가 작업본 글에서 `준비`·`확인` 후보를 뽑아 표로 보이고 사람이 고른 것만 쓴다). 길잡이 매뉴얼 탭·`checker/README.md` 도 맞췄다.
- 시험: `checker/tests/test_manual_capture.py` 에 파싱·열 전체/행 지정·다름·불능 사유·글자·종료코드 조합·하위 호환.

## 판단
- 확인이 `다름` 이어도 그림은 기존대로 찍고 파일 이름의 `_미완` 은 표시를 못 찾았을 때만 붙는다. 작업본 갱신도 표시 완료 기준 그대로다.
- `--check` 의 항목 수 키는 `확인 항목` 이다(실행 결과의 `확인` 배열과 이름이 겹치지 않게).
- 열 값은 가로로 안 보이면 `scrollColumn` 으로 먼저 보이게 하고, 세로로 안 보이는 행은 세지 않는다(`cellOf` 와 같다).
- 칸 글자가 비었는데 입력칸·체크박스·아이콘이 든 칸(`opaque`)이 비교 대상에 있으면 그 항목은 `검사 불능`(진짜 빈 칸은 `다름`, 실제 `""`).
- `{열, 값}` 은 맞음·다름 모두 `읽은 행 수` 를 낸다(보이는 행만 읽는다는 한계를 드러낸다). `--check` 의 `확인 항목` 은 확인이 있는 화면에만 붙는다.
- `글자` 는 보이는 입력칸·텍스트칸의 값도 센다. 팝업 범위가 사라지면 없다고 하지 않고 `검사 불능`.
- `글자` 는 보이는 요소 중 가장 안쪽 요소의 글에 그 글자가 들었는지(부분 일치)로 본다. 열 값만 정확히 같음.

## 확인 못 한 것
- 실제 테넌트 시험 아직. JS(`columnValues`·`hasText`)는 가짜 탭 시험만 했고 실제 Chrome·UI5 표에서 돌려 보지 못했다.
- 가로 스크롤 열 넘기기(`scrollColumn`)는 성공·실패를 알려 주지 않는다(찾으면 1, 못 찾으면 0 이고 `scrollIntoView` 는 늘 실행). 그래서 "열을 화면 안으로 넘기지 못했다" 사유는 붙이지 않았다 — 가로로 안 보이는 칸은 `gridCells` 의 온전히 보임 검사에서 빠져 행 수에 안 든다.
- `행: N` 은 지금 화면에 온전히 보이는 본문의 N번째라 표 스크롤 위치에 따라 달라진다.
- 시험 목록을 작업본 글에서 뽑는 절차(스킬 새 소절)는 글로만 정했고 실제로 돌려 보지 않았다.
- 길잡이 아티팩트 재게시는 병합 뒤에 한다.
