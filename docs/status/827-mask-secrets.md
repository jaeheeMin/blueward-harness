# #827 비밀 값을 찾는 즉시 가리기(시안 G-22) (2026-11-09)

사용자 결정: 비밀 값은 무조건 다 가린다. 방법은 보이는 것만 덮는 게 아니라 **찾는 즉시 실제 글자를 `••••••••` 로 바꾸기**(입력칸·저장·GitHub 어디에도 진짜 값이 남지 않게).

## 규칙(한 곳 기준, 두 군데 구현)

| 모양 | 가린 뒤 |
|---|---|
| `client_secret=abcd…`, `password: x`, `"api_key": "…"`(이름에 secret/password/passwd/pwd/token/api_key/access_key/private_key/credential) | 이름과 `=`·`:` 는 남기고 값만 `••••••••` |
| GitHub 토큰(`ghp_…`, `github_pat_…`), AWS 키(`AKIA…`), `sk-…`, Slack(`xox…`), JWT, `Bearer …`, 개인 키 블록 | 통째로 `••••••••` |
| 주소 속 비밀번호(`https://user:pw@host`) | `://••••••••@` |
| 값이 없는 말("password 정책을 바꿨다"), 이미 가린 값, 자리표시(`<키>`, `(생략)`) | 그대로 |

서버 `plugins/harness/console/trouble.py` `mask_secrets()`, 화면 `static/flow-logic.js` `BHLogic.maskSecrets()`. 시험 `test_mask_secrets_same_on_server_and_screen_and_masked_text_is_not_a_secret` 이 같은 샘플을 두 쪽에 넣어 결과가 같은지, 가린 글이 비밀 검사(`scan_secrets`)에 다시 걸리지 않는지 본다. 개인 키 패턴은 BEGIN 줄만이 아니라 END 까지(없으면 끝까지) 잡도록 넓혔다.

## 어디서 가리나

| 화면 | 방식 |
|---|---|
| 기록 새로 쓰기·이력 더하기 입력칸(제목·증상·원인·해결·댓글) | 입력·붙여 넣기·AI 초안·저장해 둔 글 채우기 때 **값 자체를 바꿈**, "비밀처럼 보이는 값을 가렸어." 알림 |
| 기록 목록·한 건·이력·비슷한 기록·"GitHub 에 이렇게 올라가" | 보이기 |
| 세션 대화(내 말·AI 말·결과 보고·질문 답 한 줄), 막힘 카드 본문·[검사 원문], 관리자에게 보낼 글(복사문) | 보이기 |
| 승인 카드 제목·설명·명령/파일 줄·"도구에 넘기는 입력 전체"·제안 규칙, 세션에 보낼 내용 미리보기 | 보이기 |

그대로 두는 것: Claude 에게 보내는 글, 허락하는 명령(가린 값으로 바꾸면 명령이 깨진다), 서버에 쌓인 원문. 서버 `refuse_secrets` 는 가리지 못한 비밀 모양을 저장 직전에 막는 마지막 관문으로 남긴다.

## 시안 G-22 의 비밀 줄 카드(사용자 결정 11-09)

시안 G-22 는 증상 칸의 가린 값과 함께 빨간 "✕ 올리기 전에 지워 줘 · 비밀번호·키처럼 보이는 글이 있어" 카드와 잠긴 올리기를 보인다. 찾는 즉시 가리면 남은 비밀이 없어 이 카드가 뜨지 않아 치수 검사(`check_console` G-22)가 실패했다. 사용자가 고른 안: 카드 모양은 시안대로 두고 가린 줄을 알리되 올리기는 잠그지 않는다.

| 경우 | 카드 | 올리기 |
|---|---|---|
| 가린 줄(`••••••••` 가 든 줄)만 있음 | `.tb-bad.tb-masked`: `! 확인하고 올려 줘` · `비밀번호·키처럼 보이는 글이 있어 · 가렸어` · "증상 3번째 줄의 값을 •••••••• 로 바꿨어. 필요 없는 줄이면 지워 줘." · `그 줄 지우기` | 잠그지 않음 |
| 가리지 못한 비밀(서버 검사 hits) | 원래 빨간 카드 `✕ 올리기 전에 지워 줘` | 잠금 |

가린 줄은 증상 거울에서도 비밀 줄처럼 표시하고, 카드가 보이는 동안 아래 "비밀처럼 보이는 값을 가렸어." 알림 줄은 같은 말이라 비운다. 카드는 서버 검사를 기다리지 않고 입력 즉시 그린다. 시험 `test_secret_values_are_masked_in_chat_and_record_form`(카드 문구·잠기지 않음·[그 줄 지우기]), `check_console G-22` 1440·1280 통과.
