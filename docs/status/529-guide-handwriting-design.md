# #529 길잡이에 손글씨 디자인 적용 (2026-10-29)

하네스 소개 아티팩트(https://claude.ai/artifact/GJLsDTHvhuQH1C8n98qVb3)의 손글씨 디자인을 사용자가 마음에 들어 해, 길잡이(`docs/guide/harness-guide.html`)에도 같은 디자인을 입혔다. 내용과 레이아웃(왼쪽 탭 레일, 패널 순서)은 그대로다.

- 글꼴: 기본 감자꽃(Gamja Flower). 레일 머리의 "글씨" 칸에서 손글씨(개구 + 나눔펜 · 푸어 스토리 · 하이 멜로디)와 정돈된 글씨(고운돋움 · 스타일리시 · 선플라워)로 바꾼다(`localStorage` 키 `hg-font`). 제목은 손글씨 글꼴에 굵기가 하나뿐이라 굵게 합성하지 않고, 나눔펜 제목은 `--title-scale` 로 키운다. 코드는 JetBrains Mono 그대로.
- 색: 모눈 공책 바탕, 주황(강조) · 청록(됨) · 겨자(주의) · 다홍(멈춤). 다크는 따뜻한 먹색. 기존 토큰 이름(`--accent`, `--ok` …)은 그대로 두고 값만 바꿨다.
- 크기: 손글씨는 작아 보여 본문 18px, CSS 글자 크기 15% 키움(코드 · 고정폭 제외), 줄 간격 1.8. 글 속 코드는 `li` · `.box` · `.callout` 안에서 줄바꿈을 허용했다 — 큰 글씨에서 spec-new 의 긴 표 머리 코드와 prs 의 PR 링크 예시가 상자를 넘쳤다.
- 확인: 로컬 http.server + Chrome 에서 탭 22개 × 글꼴 4종 × 넓은 화면 · 400px 폭을 돌려 페이지 가로 넘침, 상자 넘침, SVG 글자 넘침이 없음을 JS 로 쟀다.
- 관리자 보기(PR 근거 링크 표시 전환)는 소개 아티팩트에만 넣었다. 길잡이의 `#12` · `#303` 등은 설명용 예시라 근거 PR 이 없다.
- `docs/guide/README.md` "지켜 온 디자인 결정" 의 글꼴 · 다크 바탕 항목을 새 결정으로 바꿨다.
