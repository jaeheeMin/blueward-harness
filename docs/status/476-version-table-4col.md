# #476 /harness:version 기본 표를 4칸으로 줄이기 (2026-10-26)

## 문제

0.10.117 의 기본 표는 "이 세션에 실린 판" 과 "이 폴더 판"(설치 기록)을 한 줄에 같이 보여 줬다. 두 판이 다르면 "이 폴더 판 0.10.115" 옆에 "최신" 이 나와 팀원이 헷갈렸다. 판정은 #471 부터 실린 판 기준이라 기본 표에 설치 기록까지 보일 필요가 없다.

## 바뀐 것

| 곳 | 내용 |
|---|---|
| `hooks/installed_version.py` | `--all` 기본 표를 `플러그인 \| 판 \| 최신 판 \| 상태` 4칸으로. 판은 실린 판을 아는 행이면 실린 판, 그 외 설치 판. `--all-entries` 면 지금 칸 전부와 숨겼던 줄. 상태가 "갱신 있음" 이거나 실린 판을 못 읽었을 때만 표 아래에 `--all-entries` 안내 한 줄. `--json` 구조는 그대로 |
| `skills/version/SKILL.md`, `docs/guide/harness-guide.html` | 4칸 기준 설명, 레일 0.10.119 |
| `checker/tests/test_installed_version.py` | 4칸 표, 안내 줄 조건, `--all-entries` 전체 칸 |

## 결정

- 기본 표에서 "빠진 줄 N개" 문구는 없앴다(요청 범위: 안내 줄은 갱신 있음·실린 판 못 읽음일 때만).
- 열린 PR #474 가 0.10.118 을 쓰므로 이 변경은 0.10.119.
