# #763 홈·새 작업 화면을 시안 G-04·05·06 과 맞추기

## 원인

시안과 화면을 같은 창 너비(1440·1280)에서 요소별로 재 보니 구성과 숫자가 달랐다.

- 세션이 없으면 헤더 `작업` 메뉴가 빠지고, 오른쪽 이름이 `WORK/PROJ-READY` 같은 경로 조각이었다.
- 홈 입력칸 단추가 "새 작업으로" 였다.
- 새 작업의 "이렇게 진행돼" 칸이 `/harness:srs` 같은 스킬 명령을 보였고, 확인 화면(G-06)에는 "지금 단계 테두리"·"다음 갈래 칸"이 없었다.
- 확인 화면에 "어떤 일인가요? / 이 일은 …갈래야 / 설명 / 다른 갈래로 바꾸기" 줄이 따로 있었다(시안은 AI 말 한 줄). 읽을 자료는 이름·까닭·경로 세 줄, 물어볼 것은 제목 줄 + 입력칸 형태였다.
- 제목 블록이 flex 열이라 시안(한 줄 상자 안에 eb·제목·부제가 흐르는 구조)보다 6~7px 짧았고, 숫자 타일 값 줄 높이(1.3)·세션 목록 머리줄 높이(접기 단추 28px)가 시안(1.5·글자 높이)과 달랐다.

## 한 일

- 헤더: 세션이 없어도 `작업` 메뉴(갈 곳이 없으면 `/new`), 프로젝트 이름은 폴더 이름(새 작업은 고른 폴더, 세션이 없으면 `GET /api/folders/last`).
- 홈: 입력칸 단추 `보내기`. 숫자 타일·제목 블록·목록 머리줄을 시안 치수로(접기 단추는 두 글자 사이 빈 곳으로 옮겨 오른쪽 "단계 · 기억" 자리를 시안과 같게).
- 순서 칸 문구는 데이터: `workflow.json` 단계에 선택 필드 `plain`(칸 이름)·`easy`(설명)·`brief`(확인 화면 둘째 칸부터) 를 더했다. 스킬 명령은 더는 보이지 않는다. 확인 화면은 첫 칸을 지금 단계로 굵은 테두리 + "이번 세션", 끝에 다음 갈래 칸("다음 세션")을 더한다(`next.flow`, 없으면 `next.srsColumn.branches` 에서 처음으로 갈래가 있는 것).
- 새 작업(G-05): 종류 칸 아홉 개 + 입력칸 + 한 줄 점선 참고 파일 칸(누르면 `@`) + 순서 칸 + "작업 폴더는 이 프로젝트로 자동으로 정해져." 줄. 설정하기·표준 기능은 아래 "그 밖의 종류" 줄로 옮겼다(11개가 칸에 있으면 1280 에서 한 줄 더 생겨 시안과 칸 높이가 달라진다).
- 확인 화면(G-06): AI 말 한 줄에 이해한 글·갈래·까닭이 이어지고, AI가 읽을 자료는 이름 + 오른쪽 한 줄 + 체크, AI가 물어볼 것은 항목 | 값 줄(보기는 글자 단추로 미리 고름, "직접 쓰기"). 다른 갈래로 바꾸기·세션에 보낼 내용 보기는 단추 줄 아래로.
- 사용자 결정으로 남긴 것(시안 흐름 아래): 도구 단추 줄, 작업 폴더 바꾸기(`바꾸기`), 고급 설정.

## 확인

1440·1280 에서 G-04·05·06 시안과 요소별 x·y·너비·높이·글자 크기·패딩·모서리를 재서 ±2px 안(아래 "못 맞춘 것" 제외). 가로 스크롤 없음.

### 못 맞춘 것

- 시안 로고 이미지는 깨져 있어(그림이 안 뜸) 메뉴 x 가 로고 폭만큼(36px) 다르다. 콘솔 쪽 로고가 정상이다.
- 시안 참고 파일 칸의 "여기로 끌어다 놓아" 문구: 끌어다 놓기·올리기는 기능이 없어 쓰지 않았다(누르면 `@` 로 고르는 칸).
- 시안의 "AI가 읽을 자료" 오른쪽 출처("올린 파일" 등)와 질문 항목 이름("우선순위")은 데이터가 없다. 자료는 AI가 적은 까닭(없으면 폴더), 질문은 AI가 낸 질문 글을 그대로 쓴다.
- 확인 화면 AI 말은 시안 문장이 아니라 AI 가 이해한 글 + 갈래 이름·까닭이라 줄 수가 내용에 따라 늘 수 있다.
