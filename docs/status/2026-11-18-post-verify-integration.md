## 짚고 넘어간 것(결함 아님)
- 말풍선(헤더)은 사이드 목록 순서의 첫 항목(`초안 PR 세션`), 홈 덱 1/N 은 기다린 시간이 긴 항목(`PR #202`)을 먼저 보인다. 말풍선·덱은 서로 다른 목록(알림 급한 순서 / Post 대기 시간 순서)이라 설계대로. 맞추려면 판단이 필요해 손대지 않음.
- 세션 필터 `일하는 중`은 `승인 기다림`을 합쳐 센다(post-logic.js 주석), `끝남`은 끝난 세션 + 합쳐진 PR 세션이라 홈 `AI가 일하는 중`·장면 머리와 1~2 다를 수 있다. 의도된 정의.
- 가짜 세션은 마지막 활동 뒤 시간이 지나면 `일하는 중` → `쉬는 중`으로 내려간다(시험 세계 시간 경과).
- 시험 세계 한계: 파이프라인 `검토(PR)` 칸은 시험 저장소의 origin 을 GitHub 주소로 두면서 fetch 만 로컬 bare 로 돌릴 수 없어(`git remote -v` 가 `insteadOf` 를 적용해 보여 줌) 켜지 못했다 — A 의 API 시험(`test_pipeline_*`)과 A 1회차 실화면(실제 SRS 24건)으로만 확인.
- 한 번 본 뒤 재현 안 된 것: 폴더 없는 세션을 만든 직후 처음 연 화면에서 사이드 목록이 맨 위에 있고 지금 줄이 안 보였다. 같은 세션과 새로 만든 두 번째 세션을 같은 방식으로 다시 열었을 땐 0.7초부터 지금 줄이 보였다(두 번). 원인 불명, 새로 만든 직후의 한 번이라 손대지 않음.
