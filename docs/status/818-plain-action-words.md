# #818 웹 콘솔 팀원 화면의 영문 도구 이름·스킬 명령·합니다체를 쉬운 말로 (2026-11-09)

기능·동작은 그대로, 화면에 보이는 글만 바꿨다. 서버가 주는 `currentAction` 값은 그대로 두고(기술 정보에서 원문을 본다), 화면에서만 바꾼다. 판 0.10.236(#780·#773 이 0.10.231·0.10.233 을, #832 가 0.10.235 를 먼저 써서 main 위로 옮기며 올림). 길잡이 레일 표기도 0.10.236 으로.

## 바꾼 것 (전 → 후)

| 자리 | 전 | 후 |
|---|---|---|
| 왼쪽 세션 목록 둘째 줄(일하는 중) · 내 일 목록 · 홈 표 상태 칩 · 세션 화면 제목 | `Skill: harness:srs`, `Bash: git push …` | 스킬은 이름표 + " 진행 중"(예: 요구사항 문서 진행 중), 도구는 아래 표의 말. 입력 원문은 안 나온다 |
| 세션 화면 제목 아래 작은 원문 줄(`action-line`) | 긴 동작이면 원문 한 줄 | 없앴다(원문은 기술 정보) |
| 쉬는 터미널 세션 안내 (`store.py` `CANNOT_SEND_IDLE`) | 쉬는 터미널 세션에는 바깥에서 새 턴을 시작할 수 없습니다. 터미널에서 직접 이어 가십시오. | 쉬는 터미널 세션이라 여기서는 새로 시킬 수 없어. 터미널에서 이어서 말해 줘. |
| 끝난 터미널 세션 안내 (`CANNOT_SEND_ENDED`) | 끝난 터미널 세션입니다. | 끝난 터미널 세션이야. |
| 같은 안내가 두 번 나오던 것 | 다음 할 일 카드 안 + 입력칸 아래 | 입력칸 아래에만. 카드의 단추는 그대로 막히고(마우스를 올리면 이유), 카드 글은 원래 설명으로 돌아간다. "일하는 중" 이유는 카드에 그대로 |
| 첫 내 말 풍선 | `/harness:spec` 줄이 맨 위에 보임 | 그 줄만 숨김(나머지 글은 그대로). 줄 전체가 `/<플러그인>:<이름>` 일 때만, 남는 글이 없으면 그대로 둔다. Claude 에게 간 글은 안 바뀐다 |

## 도구 이름 → 쉬운 말 (`BHLogic.plainAction`)

| 서버 원문의 도구 | 화면 |
|---|---|
| `Skill: harness:<id>` / `Skill: <id>` | `<스킬 이름표> 진행 중` |
| Bash | 명령 실행 중 |
| Write·Edit·MultiEdit·NotebookEdit | 파일 고치는 중 |
| Read·Glob·Grep·LS | 파일 살펴보는 중 |
| Agent·Task | 보조에게 맡기는 중 |
| WebFetch·WebSearch | 웹에서 찾는 중 |
| `mcp__…abap…` | SAP 연결 도구 쓰는 중 |
| 그 밖의 `mcp__…` | 연결 도구 쓰는 중 |
| TodoWrite | 할 일 정리하는 중 |
| 그 밖·빈 값 | 작업하는 중 |

## 안 건드린 것

- 원문이 남는 곳: 세션 화면 "자세히 > 기술 정보" 의 현재 동작, 서브에이전트 줄.
- 서버 `server.py`·`platform_compat.py` 의 다른 합니다체 오류 문구(터미널 세션 인계 안내, 플러그인 다시 불러오기 거절 등).
- 입력칸에서 보낸 뒤 나오는 "…처리합니다/전달했습니다" 같은 짧은 알림 문구.
