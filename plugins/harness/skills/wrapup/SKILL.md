# /harness:wrapup

세션에서 다 끝내지 못한 작업을 GitHub 이슈로 등록한다.

1. 대화에서 남은 작업을 뽑는다. 미완료 할 일, 보류한 결정, 발견했지만 고치지
   않은 문제가 대상이다.
2. 각 항목을 이슈 초안으로 만들어 사용자에게 목록으로 보여준다.
3. 사용자가 고른 항목만 실제 이슈로 등록한다. 등록하지 않기로 한 항목은
   그대로 버린다. **사용자가 고르지 않은 항목은 등록하지 않는다.** 남은
   작업처럼 보인다고 임의로 이슈를 만들지 않는다.
4. 등록한 이슈 번호를 보고한다.

## 이슈 형식

이슈 제목과 본문과 라벨은
`<이 스킬의 base directory>/../../rules/issue-and-release.md` 를 따른다.
`<이 스킬의 base directory>` 는 이 스킬이 로드될 때 위에 표시되는 경로다.

## 중복 확인

이슈를 만들기 전에 같은 내용의 이슈가 이미 있는지 `gh issue list` 로 먼저
확인한다. 이미 있으면 새로 만들지 않고 그 번호를 보고한다.

## 원격이 없을 때

원격이 연결되어 있지 않으면 `gh issue create` 가 실패해 이슈를 등록할 수
없다. 그 사실을 사용자에게 알리고, 이슈 초안 목록만 보여준 채로 멈춘다.
