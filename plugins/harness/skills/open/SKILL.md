# /harness:open

터미널을 잘 모르는 사용자를 위한 스킬이다. 설명을 늘어놓지 않고 아래 한 줄을 실행한 뒤 결과를 **한 줄로만** 알린다.

1. Bash 또는 PowerShell 도구로 실행한다(둘 중 지금 쓸 수 있는 것). 스킬 본문의 `${CLAUDE_PLUGIN_ROOT}` 는 스킬이 로드될 때 지금 세션에 실린 판 폴더로 치환된다(Bash 환경변수로는 없다).

   ```
   uv run --no-project python "${CLAUDE_PLUGIN_ROOT}/console/open.py"
   ```

   큰따옴표만 쓰므로 Bash 와 PowerShell 에서 똑같이 동작한다. 경로에 공백이나 한글이 있어도 된다.

2. 출력된 한 줄을 그대로 사용자에게 알린다. 성공하면 브라우저가 열린 것이고, 실패하면 출력에 이유가 있다.
   다른 설명이나 다음 안내를 덧붙이지 않는다. 실패했을 때도 그 한 줄만 전한다.

3. 명령이 실행되지 않아 출력이 없거나 `uv` 를 찾을 수 없다는 오류가 나면, 그 사실만 한 줄로 알리고 아래를 안내한다. 터미널을 모르는 사용자가 따라 할 수 있게 명령 한두 개만 준다.
   - `uv` 가 없을 때: Windows 는 PowerShell 에서 `winget install --id astral-sh.uv -e`, macOS 는 터미널에서 `brew install uv` 를 실행한 뒤 Claude Code 를 다시 시작하고 `/harness:open` 을 다시 입력한다.
   - 출력에 `원인:` 이 있으면 그 문장을 그대로 전한다(예: 포트 권한 오류).
